미분기하 스터디

곡선과 곡면에서 리만 기하까지, 기초부터 차근차근 쌓아 가는 학습 자료

이 자료에 대하여

이 자료의 목표는 미분기하를 처음 배우는 사람이 혼자서도 교재 수준의 엄밀성에 도달하는 것이다. 미분기하 교과서처럼 기초부터 순서대로 쌓아 올리며, 26개의 장이 한 권의 책처럼 이어지게 구성했다.

다변수 미적분과 선형대수를 한 번 배운 독자를 가정한다. 위상수학과 해석학은 몰라도 된다. 필요한 만큼은 Part 0에서 다룬다. 증명을 읽는 데 익숙하지 않아도 따라올 수 있도록 각 단계의 근거를 빠짐없이 적었다.

  • Part I을 마치면 do Carmo의 곡선·곡면론 수준에 이른다.
  • Part II를 마치면 Lee의 Introduction to Smooth Manifolds 핵심 장 수준에 이른다.
  • Part III을 마치면 Lee의 Introduction to Riemannian Manifolds 전반부(측지선, 곡률, 가우스-보네) 수준에 이른다.

이 자료는 교재를 대체하지 않는다. 교재와 나란히 읽도록 만들었고, 각 절에 대응하는 교재의 절을 적어 두었다. 교재 목록은 참고문헌에 있다.

읽는 법

  • 절의 구성. 한 절은 목표와 선수 지식으로 시작하고, 동기 → 직관(그림) → 정의 → 예와 비예 → 정리와 증명 → 좌표 계산 → 요약 순서로 진행한 뒤 연습문제로 끝난다.
  • 번호. "정의 6.2.1"은 6장 2절의 첫 번째 항목이다. 정의·정리·예 등은 한 번호를 함께 쓰고, 식 (6.2.1)과 그림 6.2.1, 연습 6.2.1은 각각 따로 센다. 모든 번호는 해당 위치로 가는 링크다.
  • 연습문제. 난이도를 ★, ★★, ★★★로 표시했다. 힌트와 풀이는 접혀 있으니 먼저 스스로 풀어 본 뒤에 펼쳐 보자.
  • 상자. 본문 옆의 상자는 종류별로 색이 다르다. 직관, 주의(흔한 오해), 규약 비교(교재와 다른 표기), 나중에 보게 될 일반화, 앞에서 본 것과의 비교가 있다.
  • 호환성 명제. "호환성 명제" 표시가 붙은 명제는 뒤에서 넓힌 정의가 Part I의 정의와 일치함을 보인다. Part I·II·III을 잇는 이음매다.
  • 인용. [dC §2-4]처럼 대괄호 안의 약어는 참고 교재를 가리킨다.
  • 상태 표시. 각 장과 절에는 계획 초안 검토 완료 확정 가운데 하나가 붙는다.

함께 보는 페이지

  • 기호와 규약: 모든 장에서 쓰는 기호, 부호 규약, 교재와 다른 점, 기준 예제
  • 용어집: 한국어 용어와 영어 원어
  • 찾아보기: 각 개념이 정의된 위치와 다시 쓰이는 곳
  • 참고문헌: 인용 약어와 참고 교재

큰 줄기

여러 장을 꿰는 여섯 개의 이야기 줄기다. 한 줄기를 따라 읽으면 같은 질문이 장을 거듭하며 어떻게 넓어지고 깊어지는지 볼 수 있다.

T1. 곡률이란 무엇인가

곡선의 곡률 \(\kappa\)와 비틀림률 \(\tau\) (04–05) → 법곡률·주곡률·가우스 곡률 (08) → 빼어난 정리: \(K\)는 내재적이다 (09) → 곡률텐서와 단면곡률 (24) → 가우스 방정식으로 Part I과 다시 만남 (25)

T2. 미분과 접공간

\(\R^n\)의 전미분 \(DF(p)\) (02) → 접평면과 \(d\varphi_p\) (06) → 매끄러운 사상 (12) → derivation과 \(dF_p\) (13) → 몰입과 침몰 (14) → 벡터장과 흐름 (15) → (선택) 분포와 프로베니우스 정리 (20)

T3. 내재적 vs 외재적

부분공간 위상과 몫공간: 공간 안에 놓인 것과 스스로 주어진 것 (03) → 제1기본형식 (07) → 빼어난 정리 (09) → 둘러싼 공간 없는 추상 다양체 (11) → 리만 계량 (21) → 부분다양체의 기하 (25)

T4. 평행이동과 측지선

곡면 위의 공변미분과 측지선 (09) → 접속 (22) → 측지선과 지수사상 (23) → 야코비 장 (26)

T5. 적분과 위상

컴팩트성과 연결성 (03) → 호의 길이와 넓이 (04, 07) → 가우스-보네 정리 (10) → 단위분할 (12) → 미분형식과 스토크스 정리 (17–18) → 드람 코호몰로지 (19) → 가우스-보네 재방문 (26)

T6. 쌍대성과 텐서

쌍대공간 (01) → 여접공간과 1-형식 (16) → 미분형식 (17) → 음악적 동형 (21) → 곡률텐서 (24)

장 사이의 의존 관계

  • Part I에는 1장–3장이 필요하다. 4–5장은 1–2장만으로 읽을 수 있고, 6장부터 3장의 위상 개념이 쓰인다. Part II에는 1장–3장이 필요하다.
  • Part I과 Part II는 대부분 서로 독립이므로 어느 쪽을 먼저 읽어도 된다. 다만 11장에서 Part I의 정칙곡면과 매개화를 다양체의 언어로 다시 보는 부분은 6장을 읽은 뒤에 보는 것이 좋다.
  • Part III에는 Part II, 특히 13장–18장이 필요하고, Part I을 자주 되돌아본다.
  • "(선택)" 표시가 붙은 20장과 26장은 핵심 흐름을 마친 뒤에 읽어도 된다.
