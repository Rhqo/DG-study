18. 방향, 적분, 스토크스 정리

Part II. 매끄러운 다양체 · 대응 교재: [Lee-ISM 15–16장]

줄기: T5 적분과 위상 (스토크스 정리)

이 장의 질문

  • 미분형식을 다양체 위에서 적분하려면 무엇이 필요한가?
  • 미적분학의 기본정리는 고차원에서 어떤 모습인가?

이어받는 것

  • 1장 · 벡터공간의 방향 — 다양체의 방향
  • 2장 · 변수변환 공식 — 미분형식 적분의 좌표 무관성
  • 7장 · 곡면의 넓이 — 호환성 명제: 넓이 형식의 적분
  • 7장 · 곡면의 방향 — 다양체의 방향과 비교
  • 10장이 남긴 질문 · 가우스-보네 증명에 쓴 그린 정리는 어떤 일반 정리의 특수한 경우인가?
  • 11장 · \(\RP^n\)과 경계를 갖는 다양체 — 방향 불가능성과 스토크스 정리
  • 12장 · 단위분할 — 적분의 정의
  • 14장 · 매장 부분다양체와 포함사상 — 부분다양체 위의 적분
  • 17장 · 미분형식과 외미분 — 적분과 스토크스 정리

절 목록

  1. 18.1 다양체의 방향 계획

    내용: 벡터공간의 방향(1장)에서 다양체의 방향으로, 방향 차트, 최고차 형식으로 본 방향 · 기준 예제: \(\RP^n\)(방향 불가능성)

  2. 18.2 경계의 유도 방향 계획

    내용: 바깥 방향 법벡터, 스토크스 방향

  3. 18.3 미분형식의 적분 계획

    내용: 차트 위의 적분, 단위분할로 이어 붙이기, 좌표 무관성(변수변환 공식)

  4. 18.4 스토크스 정리 계획

    내용: 진술과 증명, 예: 그린 정리

  5. 18.5 고전적 적분 정리와 곡면의 넓이 계획

    내용: \(\R^3\)의 스토크스·발산 정리, 곡면의 넓이 형식 \(\iota_{\mathbf{N}}(dx\wedge dy\wedge dz)\) · 호환성 명제: 곡면의 넓이(7장)는 넓이 형식의 적분과 같고(리만 체적형식과의 일치는 21장), 고전적 스토크스·발산 정리는 일반 스토크스 정리의 특수한 경우다

넘겨주는 것

  • 스토크스 정리 → 19장(호모토피 불변성과 최고차 코호몰로지), 21장(발산정리), 26장(가우스-보네의 리만 기하 증명)
  • 방향과 적분 → 21장(체적형식과 리만 적분)
  • \(\R^3\) 곡면의 넓이 형식 → 21장(리만 체적형식 \(dV_g\)와의 일치)
