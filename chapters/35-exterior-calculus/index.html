  2. 35.2 The Exterior Derivative Reviewed

    Topics: differential \(df\)(strong: Section 16.2)와 \(d(x^i) = dx^i\), \(d(u^i) = du^i\)(Proposition 35.2.2); \(df\)와 \(\grad f = (df)^\sharp\)의 차이(polar coordinates의 예); exterior derivative(strong: Section 17.3)가 (D1) \(df\), (D2) graded product rule, (D3) \(d\circ d = 0\)으로 유일하게 정해지고 공식 \(d(\sum_I\alpha_I\,dx^I) = \sum_I d\alpha_I\wedge dx^I\)로 주어짐(Theorem 35.2.4, 완전한 증명), 부호를 빼면 모순(Non-example), 어느 좌표에서나 같은 공식(Proposition 35.2.6); grad, curl, div 사전과 curl∘grad = 0, div∘curl = 0(Proposition 35.2.8, Corollary 35.2.9); diagram view; closed와 exact(strong: Section 19.1), \(d\theta\)는 closed이고 exact가 아님(Proposition 35.2.11, slit plane 논법); Laplacian(strong) \(\Delta f = \star d\star df = \divg\grad f\)(Proposition 35.2.12)와 polar 공식 · Conventions: Laplacian의 부호(Notation) · Running examples: saddle \(x^2 - y^2\)(\(\star df = d(2xy)\)), \(x\,dy\), \(d\theta\), \(\log r\) · Implementation: sympy로 쓴 \(d\) · Lecture: L6 · Notes: Cr §4.6
