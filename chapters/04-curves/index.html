4. 곡선의 기초

Part I. 곡선과 곡면 · 대응 교재: [dC §1-2–1-3, 1-5 일부], [Pr 1–2장]

줄기: T1 곡률이란 무엇인가 (시작: 평면곡선의 곡률) · T5 적분과 위상 (시작: 호의 길이)

이 장의 질문

  • 곡선의 ‘길이’와 ‘휘어진 정도’를 매개화와 무관하게 정의할 수 있는가?
  • 휘어진 정도(곡률)만 알면 곡선을 되살릴 수 있는가?

이어받는 것

  • 1장 · 내적과 노름(정의 1.5.1, 정의 1.5.4), 코시-슈바르츠 부등식(정리 1.5.5), 정규직교기저에서의 전개(명제 1.5.9) — 속력, 길이, 곡률의 계산
  • 1장 · 평면의 회전 \(R_\alpha\)(예 1.2.2), 행렬식과 방향(정의 1.6.6, 정의 1.6.11) — 부호곡률의 \(J = R_{\pi/2}\)와 부호, 평면의 강체운동
  • 2장 · 전미분과 야코비 행렬(정의 2.1.1, 정리 2.1.11), 원과 나선의 속도(예 2.1.15) — 속도벡터
  • 2장 · 곱의 미분과 연쇄법칙(명제 2.2.5, 예 2.2.4, 예 2.2.6), 매끄러운 사상(정의 2.2.11), 테일러 정리(보조정리 2.2.16), \(e^{-1/t}\)(예 2.2.20) — 재매개화와 접촉원의 계산, 매끄럽지만 자취가 꺾이는 곡선(연습 4.1.7)
  • 2장 · 역함수 정리(정리 2.3.5)와 그 1변수 판(예 2.3.11), 극좌표 사상(예 2.3.10) — 호의 길이 매개화의 존재(4.2절에서 1변수 방법으로 다시 증명), 정칙곡선은 국소적으로 그래프
  • 3장 · 최댓값·최솟값 정리(정리 3.6.10) — 꺾은선 근사의 오차 상한(4.2절), 접촉원의 접촉 차수 추정(4.5절)
  • 3장 · 중간값 정리(따름정리 3.7.6) — 1변수 역함수 정리(4.2절), 접선각 함수의 유일성(4.4절)

절 목록

  1. 4.1 매개곡선과 속도벡터 검토 완료

    내용: 매개곡선과 그 자취, 평면곡선, 속도벡터와 속력, 크기가 일정한 벡터값 함수, 비예: 뾰족점이 있는 곡선 \(y^2 = x^3\) · 기준 예제: 원·나선의 속도; 구면 위의 위도원·경선·대원 소개

  2. 4.2 정칙곡선과 호의 길이 검토 완료

    내용: 정칙곡선과 특이점, 접선, 1변수 역함수 정리, 정칙곡선은 국소적으로 그래프, 호의 길이와 곡선의 길이 \(L(\gamma)\), 선분이 가장 짧다, 내접 꺾은선 근사(오차 상한) · 기준 예제: 원·나선의 길이

  3. 4.3 재매개화 검토 완료

    내용: 재매개화와 방향, 길이의 재매개화 불변성, 호의 길이 매개화의 존재와 유일성 · 기준 예제: 원·나선의 호의 길이 매개화

  4. 4.4 평면곡선의 부호곡률 검토 완료

    내용: 단위접벡터, \(\kappa_s\)와 \(\mathbf{n}_s\), 일반 매개변수 공식, 변환 법칙, 접선각과 \(\kappa_s = d\theta/ds\), 부호곡률이 곡선을 결정함 · 기준 예제: 원(\(\kappa_s = \pm 1/r\))

  5. 4.5 접촉원과 곡률중심 검토 완료

    내용: 곡률중심, 곡률반지름 \(1/\abs{\kappa_s}\), 접촉원(2차 접촉, 세 점 원의 극한), 축폐선, 공간 속 평면곡선 · 기준 예제: 구면(대원 \(1/r\)·위도원 \(1/(r\sin\theta_0)\)의 곡률과 곡률중심); 원(곡률 \(1/r\), 접촉원)

넘겨주는 것

  • 단위접벡터 \(\mathbf{t}\)(정의 4.4.1)와 호의 길이 매개화(정리 4.3.9) → 5장(공간곡선의 곡률과 프레네 틀. 5장은 \(\mathbf{t}\)를 다시 정의하지 않고 인용한다)
  • 평면에 놓인 곡선의 \(\abs{\gamma''}\)와 곡률중심 \(\gamma + \gamma''/\abs{\gamma''}^2\)(명제 4.5.10), 접촉원(정의 4.5.1) → 5장(\(\kappa = \abs{\gamma''}\), 주법선벡터, 접촉평면 안의 접촉원)
  • 나선의 호의 길이 매개화(예 4.3.10) → 5장(나선의 \(\kappa, \tau\))
  • 접선각 함수(보조정리 4.4.8), \(\kappa_s = d\theta/ds\)와 전체 곡률(정리 4.4.9), 닫힌 곡선의 \(\int\kappa_s \in 2\pi\Z\)(연습 4.4.8) → 5장(회전지수와 접선회전정리)
  • 평면곡선의 기본정리(정리 4.4.10, 따름정리 4.4.11) → 5장(곡선론의 기본정리의 평면 판)
  • 호의 길이와 길이의 재매개화 불변성(정의 4.2.7, 정리 4.3.6) → 7장(곡면 위 곡선의 길이), 21장(\(L_g(\gamma)\))
  • 재매개화와 방향(정의 4.3.1, 정의 4.3.2) → 6장(매개변수 변환: 정리 6.3.1), 7장(곡면의 방향)
  • 선분이 가장 짧다(따름정리 4.2.10) → 23장(측지선의 국소 최단성)
  • 평면곡선의 부호곡률(정의 4.4.2) → 9장(측지곡률의 모형), 10장(경계항)
  • 구면: 대원의 곡률 \(1/r\)과 곡률중심 \(O\)(예 4.5.11), 위도원의 곡률 \(1/(r\sin\theta_0)\)과 곡률중심 \((0, 0, r\cos\theta_0)\), 곡률벡터의 법선 성분 \(1/r\)과 접선 성분 \(\abs{\cot\theta_0}/r\)(예 4.5.12) → 5장(구면 위 원의 프레네 틀), 8장(법곡률), 9장(측지곡률, 측지선 = 대원)
  • 남긴 질문: 평면을 벗어나는 곡선의 모양은 곡률 하나로 정해지는가? → 5장(비틀림률)
