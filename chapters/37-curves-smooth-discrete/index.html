37. Curves: Smooth and Discrete

Track 2. Discrete Differential Geometry · Lectures: [CMU-DDG L10] (video, slides), [CMU-DDG L11] (video, slides) · References: [Cr §3.3]

Threads: T1 What is curvature? (curvature and torsion of curves, smooth and discrete; fundamental theorems) · T5 Integration and topology (turning number, the Whitney–Graustein theorem)

Questions

  • curve의 differential, tangent, curvature, torsion을 form의 언어로 쓰면 discrete curve(polygon)에서는 각각 무엇이 되고, smooth 이론의 fundamental theorem은 discrete에서도 정확히 성립하는가?
  • curve의 어떤 양은 모양을 결정하고, 어떤 양(turning number)은 연속적인 변형으로도 바뀌지 않는가? 그리고 curve를 에너지의 gradient flow로 움직이려면 시간 간격을 어떻게 다루어야 하는가?

  • Chapter 35: curve의 differential \(d\gamma\)는 구간 위의 \(\R^2\)·\(\R^3\)-valued 1-form이다(vector-valued form Definition 35.5.10, map의 differential Example 35.5.11). Section 37.1은 이것을 상기만 하고 \(d\gamma_t\)를 점마다의 linear map으로 쓴다. edge vector가 \(d\gamma\)를 edge 위에서 적분한 것이라는 Proposition 37.4.1은 Proposition 35.4.6(fundamental theorem for line integrals)을 성분마다 쓴 가장 단순한 경우다.
  • Chapter 36: 이 장은 Chapter 36의 정의를 쓰지 않는다. Section 37.1과 37.4의 상자가 edge vector \(d_0\gamma\)(primal 1-form, Definition 36.1.6, Definition 36.4.1)와 turning angle(dual 0-form, Definition 36.5.2)을 그 언어로 다시 읽는다.

    Topics: parametrized plane curve(strong: Definition 4.1.1)의 differential \(d\gamma_t(X) = X\gamma'(t)\)가 tangent vector를 늘이는 방식(Proposition 37.1.2: reparametrization에서 \(d\tilde\gamma_u(Y) = d\gamma_{h(u)}(h'(u)Y)\)); regular curve = immersion(strong: Definition 4.2.1)과 cusp \((t^3, t^2)\); embedded curve(strong)와 non-example(figure-eight를 \((0, 2\pi)\)로 제한한 injective immersion); signed curvature 상기(Section 32.2); fundamental theorem of plane curves(Theorem 4.4.10 상기)의 복원 절차(Derivation)와 rigid motion의 자유도; Proposition 37.1.7(증명): closed curve가 되는 두 조건 \(\int\kappa \in 2\pi\Z\), \(\int\mathbf{t} = 0\); \(\kappa = 1 + a\cos s\)는 \(a = 0.5\)에서 닫히지 않고(간격 \(2\pi J_1(0.5) = 1.5222\)) \(a = 3.8317\)에서 닫힌다 · Running examples: circle, ellipse(\(\kappa_s\)에서 수치 복원, 오차 \(O(m^{-2})\)), flower curve, figure-eight · Conventions: Chapter 37의 기호, 강의(\(\kappa = \inner{N}{T'}\))와 노트(\(dT = -\kappa N\))의 plane curve 부호 · Implementation: curvature에서 곡선 복원 · Exercises: 5개(Coding 1) · Go deeper: Chapter 4, Section 0.2 · Lecture: L10 slides 3–27 · Notes: Cr §3.3

  2. 37.2 Turning Number and the Whitney–Graustein Theorem Reviewed

    Topics: space curve의 curvature, torsion, Frenet frame 상기(Theorem 5.3.1); Proposition 37.3.2(증명): orthonormal frame의 미분 \(F' = FA\), \(A\) antisymmetric; Frenet–Serret를 Implementation으로 적분(helix 복원); adapted frame(dfn)과 그 방정식(Proposition 37.3.7); Bishop frame(dfn), 존재와 유일성(Proposition 37.3.9), Frenet frame에 대해 \(\vartheta' = -\tau\)(Proposition 37.3.10); inflection에서 Frenet frame이 뒤집히는 예; closed curve의 holonomy \(-\int\tau\,ds \pmod{2\pi}\)(Proposition 37.3.13) · Conventions(slide 대조 완료): 강의와 노트는 \(T' = -\kappa N\), \(N' = \kappa T - \tau B\), \(B' = \tau N\)이므로 \(\tau_{\text{Crane}} = -\tau\)이고 \(\kappa_{\text{Crane}} = \pm\kappa\)(\(N\)의 선택에 따름); helix 슬라이드의 \(\kappa = -a\)는 같은 강의의 행렬과 부호가 맞지 않는다 · Running examples: helix \((1, 0.3)\)(\(\kappa = 0.91743\), \(\tau = 0.27523\), Bishop frame이 한 바퀴에 \(-1.80546\) 회전), plane cubic \((t, t^3, 0)\), trefoil(holonomy \(3.0270\)) · Interactive: helix의 Frenet과 Bishop frame · Exercises: 5개(Coding 1) · Go deeper: Chapter 5, Section 0.2 · Lecture: L10 slides 35–45 · Notes: Cr §3.3.1
