8. 가우스 사상과 제2기본형식

Part I. 곡선과 곡면 · 대응 교재: [dC §3-2–3-3]

절 목록

  1. 8.1 가우스 사상과 형태작용소 초안

    내용: 가우스 사상 \(\mathbf{N}\colon S \to S^2\), \(d\mathbf{N}_p \in \End(T_pS)\), 자기수반 선형변환, \(d\mathbf{N}_p\)의 자기수반성, 형태작용소 \(W_p = -d\mathbf{N}_p\), 법벡터 규약 · 기준 예제: 평면·구면·원기둥·안장면의 가우스 사상, 원환면의 \(W_p\)

  2. 8.2 제2기본형식과 법곡률 초안

    내용: \(\mathrm{II}_p\), 가속도의 법선 성분, 법곡률 \(\kappa_n\), 뫼니에 정리, 접평면 위의 그래프, 법단면, \(\mathrm{II}\) = 높이의 헤세 형식 · 기준 예제: 구면 위의 곡선, 원기둥 위의 나선, 안장면의 법단면

  3. 8.3 주곡률과 주방향 초안

    내용: 고윳값과 2차원 스펙트럼 정리, 주곡률·주방향, 오일러 공식, 배꼽점과 배꼽점만으로 된 곡면, 곡률선(로드리게스), 회전면의 주곡률 · 기준 예제: 원환면(\(1/r\), \(\cos u/(R + r\cos u)\)), 회전면, 현수면

  4. 8.4 가우스 곡률과 평균곡률 초안

    내용: \(K = \det W_p\), \(H = \tfrac12\tr W_p\), 점의 분류, 점근방향, 컴팩트 곡면의 타원점, 가우스 사상의 넓이 비율로서의 \(K\) · 기준 예제: 원기둥(\(K = 0\)이지만 \(H \neq 0\)); 원환면(\(K\)의 부호 분포); 회전면(\(K = -\rho''/\rho\))

  5. 8.5 국소좌표 공식 초안

    내용: 계수 \(L, M, N\)과 그 변환, 바인가르텐 방정식, \(K\)와 \(H\)의 공식, 그래프 곡면, 타원점·쌍곡점 근처의 모양 · 기준 예제: 구면(\(L, M, N\)과 \(K = 1/r^2\)); 원기둥; 원환면(\(L, M, N\), \(H\)); 회전면; 안장면(원점에서 \(K = -4\), \(H = 0\), 모든 점이 쌍곡점)

넘겨주는 것

  • \(L, M, N\)(정의 8.5.1)과 바인가르텐 방정식(명제 8.5.4, 식 (8.5.6)) → 9장(가우스 공식의 법성분, 가우스 방정식과 코다치-마이나르디 방정식)
  • 가우스 곡률 \(K\)(정의 8.4.1)와 국소좌표 공식 \(K = (LN - M^2)/(EG - F^2)\)(정리 8.5.5) → 9장(빼어난 정리), 10장(가우스-보네의 피적분 함수; 원환면의 두 절반의 적분 \(\pm 4\pi\): 연습 8.4.5), 24장(호환성 명제: 2차원의 단면곡률)
  • 형태작용소 \(W_p = -d\mathbf{N}_p\)(정의 8.1.12)와 자기수반성(정리 8.1.10), 제2기본형식(정의 8.2.1)과 가속도의 법선 성분(명제 8.2.3) → 25장(호환성 명제: \(W_N = W_p\), 벡터값 제2기본형식)
  • 2차원 스펙트럼 정리(정리 8.3.3)와 주곡률(정의 8.3.4) → 25장(초곡면의 주곡률, \(n\)차원 판)
  • 법곡률(정의 8.2.4)과 뫼니에 정리(정리 8.2.5), 나선의 곡률은 전부 법선 성분(예 8.2.7) → 9장(측지곡률 \(\kappa^2 = \kappa_n^2 + \kappa_g^2\), 원기둥의 측지선 = 나선)
  • 컴팩트 곡면의 타원점(정리 8.4.9)과 넓이 비율(명제 8.4.11) → 10장(곡률의 부호와 위상)
