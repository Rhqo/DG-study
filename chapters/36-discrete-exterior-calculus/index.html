  1. 36.1 Discretization: The de Rham Map Reviewed

    Topics: DEC의 동기와 기본 연산 지도(\(d\), \(\star\), 그 합성); discretization과 interpolation의 구분; de Rham map(dfn: smooth \(k\)-form \(\alpha\)를 oriented \(k\)-simplex마다의 적분값 \(\hat\alpha_\sigma = \int_\sigma\alpha\)의 배열로 보내는 map); 0-form(vertex 값), 1-form(edge 위 line integral, 예), 2-form(triangle 위 적분); Proposition(증명): simplex의 orientation을 뒤집으면 값의 부호가 바뀐다; discrete differential form(dfn: oriented \(k\)-simplex마다 실수 하나, \(\alpha\in\R^{n_k}\). vector encoding과 Notation의 edge 번호(dgdec.edge_list 순서)); integrated quantity라는 관점(pointwise 값이 아니다) · Running examples: planar grid_mesh와 1-form \(x\,dy\)(edge 적분을 정확히), \(f = x^2 - y^2\)의 \(df\)(edge 값 = 끝점 값의 차), triangle 하나 위의 2-form, icosphere 위 높이 함수 \(z\)(0-form) · Conventions: \(\hat\alpha\) 표기와 orientation 규약(Notation).   2. 36.2 Chains and Cochains Reviewed

    Topics: simplicial chain(dfn: oriented \(k\)-simplex의 linear combination(coefficient는 실수), \(-\sigma\) = 반대 orientation. 정수 coefficient의 표준 정의는 Conventions 상자)과 그 덧셈; boundary operator(dfn: \(\partial(v_0\cdots v_k) = \sum_m(-1)^m(v_0\cdots\widehat{v_m}\cdots v_k)\)를 chain으로 linear하게 확장); Theorem(완전한 증명): \(\partial\circ\partial = 0\); 행렬로: \(\partial_1 = d_0^{\mathsf T}\), \(\partial_2 = d_1^{\mathsf T}\)(Section 33.5의 signed incidence matrix와 연결; Proposition); cochain(dfn: chain 위의 linear functional)과 pairing \(\langle\alpha, c\rangle\)(chain 위의 “적분”); coboundary operator(dfn: \(\partial\)의 dual, \((d\alpha)(c) = \alpha(\partial c)\). 이것이 Section 36.4의 discrete exterior derivative다); Proposition(증명): discrete differential form과 cochain의 동일시 \(\R^{n_k}\cong C^k\), de Rham map은 \(\langle\hat\alpha, c\rangle = \int_c\alpha\)를 만족; cycle과 boundary(진술만. homology는 Section 45.2) · Running examples: 평면 grid 위의 path와 loop, triangle과 3-simplex(tetrahedron)의 \(\partial\) 손계산, annulus에서 boundary가 아닌 1-cycle(\(\widehat{d\theta}\)로 판별) · Helpers: dgdec.boundary1, boundary2, d0, d1 · Go deeper: [Hatcher02](simplicial homology), Chapter 19, Section 18.4 · Lecture: L8 slides 24–32 · Notes: 노트에는 없다(슬라이드만)

  3. 36.3 Interpolation: Whitney Forms Reviewed

    Topics: 0-form의 interpolation: barycentric coordinates(Section 33.1 상기)를 hat function \(\varphi_i\)로 보는 piecewise linear interpolation; Whitney form(dfn: Whitney 1-form \(\varphi_{ij} = \varphi_i\,d\varphi_j - \varphi_j\,d\varphi_i\), Whitney 2-form \(2(\varphi_i\,d\varphi_j\wedge d\varphi_k + \varphi_j\,d\varphi_k\wedge d\varphi_i + \varphi_k\,d\varphi_i\wedge d\varphi_j)\)); Whitney map(dfn: \(W\hat\alpha = \sum_\sigma\hat\alpha_\sigma\varphi_\sigma\)); Theorem(완전한 증명): \(\int_{\sigma'}\varphi_\sigma = \delta_{\sigma\sigma'}\)이므로 \(R\circ W = \id\)(\(R\)은 de Rham map), \(W\circ R \ne \id\)(예); Proposition(완전한 증명): \(Wd = dW\)(0-form과 1-form), 따라서 상수 form은 정확히 재현된다(Corollary); Whitney 1-form의 tangential 성분이 edge를 건너 연속임; 그림: triangle 위 세 Whitney 1-form의 vector proxy \(\varphi_{ij}^\sharp\) · Running examples: reference triangle(직각이등변)과 Example 33.1.10의 triangle, 두 triangle(lib/ch36.kite), planar grid 위 \(x\,dy\)의 \(WR\) 근사와 오차, icosphere(1)(연습) · Helpers: dgdec.barycentric_coordinates, barycentric_gradients, whitney_basis, whitney_interpolate, whitney_at_barycenters · Overlap: hat function과 그 gradient는 Section 42.3(FEM)에서 여기의 \(\varphi_i\)를 상기해 쓴다 · Go deeper: [Whitney57], [Desbrun08], Section 31.3(Looking back) · Lecture: L8 slides 33–39 · Notes: 노트에는 없다(슬라이드만)

  4. 36.4 The Discrete Exterior Derivative Reviewed

    Topics: 동기: Stokes \(\int_\sigma d\alpha = \int_{\partial\sigma}\alpha\)(Section 35.4)를 정의로 삼는다; discrete exterior derivative(dfn: \((d\hat\alpha)_\sigma := \hat\alpha(\partial\sigma)\), 즉 Section 36.2의 coboundary); 0-form은 \((d_0u)_{ij} = u_j - u_i\), 1-form은 triangle 둘레의 부호 있는 합(부호 = relative orientation); 행렬 \(d_0\in\R^{n_1\times n_0}\), \(d_1\in\R^{n_2\times n_1}\)이 Section 33.5의 signed incidence matrix임(Proposition); Theorem(완전한 증명): discrete Stokes \(\langle d\alpha, c\rangle = \langle\alpha, \partial c\rangle\); Theorem(완전한 증명): \(d\)는 discretization과 commute한다, \(R\,d = d\,R\); Theorem(완전한 증명): \(d_1d_0 = 0\)(Section 36.2의 \(\partial\partial = 0\)에서); discrete closed와 exact 1-form, 예: 평면 grid의 exact 1-form, torus_mesh에서 closed이지만 exact가 아닌 1-form(Section 45.2 예고) · Smooth vs. Discrete: \(dd = 0\)과 Stokes는 mesh 위에서 근사가 아니라 정확한 항등식이다 · Running examples: tetrahedron의 \(d_0, d_1\) 손계산, planar grid의 \(df\), icosphere에서 \(d_1d_0 = 0\) 확인 · Helpers: dgdec.d0, d1, derham0, derham1, derham2 · Go deeper: Section 17.3, Section 19.1 · Lecture: L9 slides 3–13 · Notes: Cr §4.8.3

  5. 36.5 Dual Forms and the Discrete Hodge Star Reviewed

    Topics: 조합적 dual complex 상기(Section 33.6)와 dual cell \(\sigma^\star\)의 orientation 규약(primal edge를 +90° 돌린 방향 등. 부호의 정본은 dgdec); dual discrete form(dfn: dual cell 위의 값. primal form과는 더할 수 없다)과 그 해석(primal 1-form = circulation, dual 1-form = flux); dual exterior derivative \(\tilde d = \pm d^{\mathsf T}\)(Proposition, 증명; 부호 규약 명시); dual의 기하: circumcentric dual(dfn: triangle의 circumcenter, edge의 midpoint, vertex 자신을 잇는 dual), primal과 dual이 orthogonal함, obtuse triangle에서 signed dual 길이가 음수가 됨; discrete Hodge star(dfn: primal \(k\)-form을 dual \((n-k)\)-form으로 보내는 map), diagonal Hodge star(dfn: \(\star_k = \diag(\abs{\sigma^\star}/\abs{\sigma})\), “primal 부피로 나누고 dual 부피를 곱한다”); \(\star_0\) = dual cell 넓이, \(\star_2\) = 1/넓이; Theorem(완전한 증명. cotan formula를 증명하는 유일한 곳): circumcentric dual에서 \(\abs{e_{ij}^\star}/\abs{e_{ij}} = \tfrac12(\cot\alpha_{ij} + \cot\beta_{ij})\), 따라서 \(\star_1 = \diag\bigl(\tfrac12(\cot\alpha + \cot\beta)\bigr)\); 다른 선택(barycentric dual, Galerkin Hodge star)과 비교. 어느 것도 정확하지 않다(Chapter 32의 no free lunch와 연결) · Running examples: 정삼각형 grid(모든 cot이 \(1/\sqrt3\)), obtuse triangle(음의 weight), icosphere의 \(\star_0\) 합 = 전체 넓이 · Conventions: Notation 기호 \(\star_0, \star_1, \star_2\), \(\sigma^\star\). Crane은 \(\hat\star\)로 쓴다 · Helpers: dgdec.circumcenters, primal_edge_lengths, dual_edge_lengths, dual_areas, hodge0, hodge1, hodge2, hodge_inverse · Overlap: dual complex의 조합적 정의는 Section 33.6. surface mesh 위의 \(\star\)는 Section 38.6 · Go deeper: [Hirani03], [Desbrun05], Section 31.3 · Lecture: L9 slides 14–29 · Notes: Cr §4.8.4

  6. 36.6 Composing Operators Reviewed

    Topics: 기본 연산표(\(d_0, d_1, \star_0, \star_1, \star_2\), dual \(d\))와 합성으로 얻는 vector calculus: gradient(\(d_0\)), curl(\(\star_2d_1\)), divergence(\(\star_0^{-1}d_0^{\mathsf T}\star_1\)과 부호 규약); discrete codifferential(dfn: \(d^* = \star^{-1}d^{\mathsf T}\star\). Section 35.5의 L2 adjoint를 \(\star\)-inner product로; Proposition(증명): adjoint임); cotan Laplacian(dfn: \(L := -d_0^{\mathsf T}\star_1d_0\), 즉 \(L_{ij} = \tfrac12(\cot\alpha_{ij} + \cot\beta_{ij})\), \(L_{ii} = -\sum_jL_{ij}\); Notation); Proposition(증명): \(L\)은 symmetric이고 행의 합이 0이며, \(\star_1\)의 대각 원소가 모두 양이면(Delaunay) \(-L\)은 positive semidefinite이고 connected mesh에서 kernel은 상수(일반 mesh의 positive semidefiniteness는 Section 42.3에서 Dirichlet energy로 증명); discrete Laplacian \(\star_0^{-1}L\approx\Delta = \divg\grad\)(\(\star_0\)는 Chapter 42에서 mass matrix \(M\)이 된다는 한 문장 지시); 평면 grid의 Poisson 문제 \(Lu = \star_0f\) 풀기(Implementation, numpy dense solve); 다른 discrete 연산(wedge, interior product)은 진술만(Cr §4.8.5) · Conventions(Conventions box): \(-L\)이 positive semidefinite이고 \(M^{-1}L\approx\Delta\)(Notation). Crane의 L9와 많은 코드는 positive semidefinite 쪽 행렬(\(d_0^{\mathsf T}\star_1d_0\))을 Laplacian이라 부른다 · Running examples: 정삼각형 grid의 \(L\)(7점 stencil), planar grid 위 harmonic 함수 \(x^2 - y^2\)에 대한 \(Lu\)(interior에서 0), icosphere의 \(L\mathbf{1} = 0\) · Helpers: dgdec.laplacian_psd, hodge0, hodge1, hodge2; dgmesh.cotan_laplacian, cotan_weights · Overlap: \(L\)의 정의는 여기 한 곳이다. surface 위의 해석은 Section 38.6, mean curvature normal은 Section 40.3, area gradient는 Section 41.2, FEM 유도와 일반 positive semidefiniteness는 Section 42.3, dual cell 적분 유도와 행렬 조립은 Section 42.4 · Go deeper: Definition 31.3.3(Looking back), Section 21.6 · Lecture: L9 slides 30–35 · Notes: Cr §4.8.4–4.8.5, §4.6.6
