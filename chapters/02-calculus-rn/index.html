Sections

  1. 2.1 The Total Derivative: Differentiation as Linear Approximation Reviewed

    Topics: 미분가능성과 total derivative \(DF(p)\), partial derivative·directional derivative·Jacobian matrix, partial derivative가 연속이면 미분가능 · Running examples: polar coordinate map \(P(r, \theta)\), 원·helix의 속도, sphere parametrization의 total derivative(coefficient 2)

  2. 2.2 The Chain Rule and Higher Derivatives Reviewed

    Topics: chain rule, 곡선으로 계산하는 total derivative, 곱의 미분, operator norm과 mean value inequality, \(C^k\)와 smooth map, partial derivative의 교환, Taylor's theorem, smooth coefficient를 갖는 1차 전개, \(e^{-1/t}\) · Running examples: 북극 근처의 sphere

  3. 2.3 The Inverse Function Theorem Reviewed

    Topics: diffeomorphism, inverse function theorem(contraction mapping principle에 의한 proof sketch), local diffeomorphism, 1변수의 경우 · Running examples: polar coordinate map(국소적으로 invertible, 대역적으로 injective가 아님)

  4. 2.4 The Implicit Function Theorem and Level Sets Reviewed

    Topics: level set, implicit function theorem(inverse function theorem으로 증명), gradient, level set은 국소적으로 그래프, level set 위 곡선의 속도 = \(\ker DF(p)\)(regular value의 예고) · Running examples: 원, sphere, saddle surface의 level curve

  5. 2.5 The Rank Theorem Reviewed

    Topics: linear map의 normal form, rank의 lower semicontinuity, rank theorem(증명), surjective·injective인 경우의 local canonical form · Running examples: graph surface

  6. 2.6 Integration and the Change of Variables Formula Reviewed

    Topics: Riemann 적분 복습(set of content zero, domain of integration, Fubini's theorem), linear map과 부피, change of variables formula(proof sketch), Green's theorem(진술) · Running examples: polar coordinates·spherical coordinates, torus of revolution의 부피

  7. 2.7 Existence and Uniqueness for Ordinary Differential Equations Reviewed

    Topics: initial value problem, 국소 존재·유일성·초기값에 대한 smooth 의존성(진술), maximal solution과 군 성질, escape lemma, 고계·시간 의존·매개변수 방정식, linear 방정식의 전역 존재 · Running examples: 진자
