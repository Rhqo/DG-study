3. 위상공간 기초

Part 0. 준비 · 대응 교재: [Lee-ITM 2–4장], [Lee-ISM 부록 A]

줄기: T3 내재적 vs 외재적 (첫 지점: 부분공간 위상(공간 안에 놓인 것)과 몫공간(스스로 주어진 것), 3.3절·3.4절) · T5 적분과 위상 (컴팩트성·연결성, 3.6절·3.7절)

이 장의 질문

  • ‘가까움’과 ‘연속’을 거리 없이 말할 수 있는가?
  • 공간을 ‘이어 붙여’ 새 공간을 만들 수 있는가?

이어받는 것

  • 정의 1.5.4 (노름), 따름정리 1.5.6 (삼각부등식, 유클리드 거리) (1장) — 거리공간의 가장 기본적인 예. 거리의 공리에서 열린집합으로, 열린집합에서 위상으로 간다(3.1절)
  • 명제 1.2.14 (행렬 표현), 명제 1.5.7 (선형사상은 유계) (1장) — 선형사상 \(\R^n \to \R^m\)의 연속성(3.2절)
  • 정의 1.6.6 (행렬식) (1장) — \(\det\)이 연속이므로 \(\GL(n, \R)\)은 열려 있고(3.2절) 연결이 아니다(3.7절)
  • 명제 1.2.12, 정의 1.2.11 (동형사상, \(\cong\)) (1장) — 선형 동형사상의 역사상은 저절로 선형이지만 연속 전단사의 역사상은 그렇지 않다(3.2절의 비교 상자). 기호 \(\cong\)는 이 장에서 위상동형을 뜻한다
  • 명제 1.6.12 (방향은 정확히 두 개다) (1장) — 기저들 위의 “같은 방향” 관계가 첫 동치관계의 예다. 정의 3.4.1에서 임의의 집합 위의 동치관계와 몫집합으로 일반화한다(3.4절)
  • 2.1절의 준비(거리, 공, 열린집합, 극한, 컴팩트 집합) (2장) — 미적분학의 약속으로만 쓴 개념을 3.1–3.2절에서 정식으로 정의한다. 예 2.3.2(c)의 미분동형사상 \(B_1(0) \to \R^n\)은 예 3.2.14(b)에서, 2.5절의 8자 곡선은 비예 3.3.11에서 위상의 언어로 다시 본다
  • 2.1절 준비의 경계점과 폐포의 약속, 그것을 쓴 정의 2.6.6과 정리 2.6.9 (2장) — 약속이 정의 3.1.15의 폐포와 같음을 명제 3.1.27에서 증명한다(3.1절)
  • 정의 2.3.1 (미분동형사상), 비예 2.3.3 (2장) — 위상동형사상과 미분동형사상의 차이(3.2절의 용어 주의)
  • 따름정리 2.2.10 (2장) — 공 위에서 \(DF = 0\)이면 상수. 연결인 열린집합으로 넓힌다(따름정리 3.7.18, 3.7절)

절 목록

  1. 3.1 열린집합과 위상공간 검토 완료

    내용: 거리공간과 열린공, 열린집합의 세 성질, 위상공간과 근방, 닫힌집합과 폐포, 위상의 기저, 같은 위상을 주는 거리(\(d, d_\infty, d_1\))

  2. 3.2 연속사상과 위상동형사상 검토 완료

    내용: 열린집합으로 본 연속성과 \(\varepsilon\)-\(\delta\), 역상 판정(\(S^n\), \(\GL(n,\R)\)), 열린사상, 위상동형사상(\(B_1(0) \cong \R^n\), 입체사영), 비예 \([0, 2\pi) \to S^1\), 수열의 수렴

  3. 3.3 부분공간과 곱공간 검토 완료

    내용: 부분공간 위상과 특징적 성질, 붙이기 보조정리, 위상 매장(비예: 8자 곡선), 곱위상과 특징적 성질 · 기준 예제: 토러스 \(T^2 = S^1 \times S^1 \cong\) 원환면(위상동형)

  4. 3.4 몫공간 검토 완료

    내용: 동치관계, 몫위상과 몫사상의 특징적 성질, \(\R/\Z \cong S^1\) · 기준 예제: 토러스(정사각형의 몫공간); \(\RP^n\)(몫위상, \(S^n/{\pm} \cong \RP^n\), \(U_i \cong \R^n\))

  5. 3.5 하우스도르프 조건과 제2가산 조건 검토 완료

    내용: 두 조건의 뜻과 필요성, 극한의 유일성, 비예: 원점이 두 개인 직선, \(\R \times \R_{\text{이산}}\) · 기준 예제: \(\RP^n\)(하우스도르프, 제2가산)

  6. 3.6 컴팩트성 검토 완료

    내용: 열린덮개, 곱의 컴팩트성(튜브 보조정리), 하이네-보렐 정리, 최댓값·최솟값, 닫힌사상 보조정리, 린델뢰프 성질, 부분수열, 르베그 수와 균등연속 · 기준 예제: 토러스(\([0,1]^2/{\sim} \cong T^2\)); \(\RP^n\)(컴팩트)

  7. 3.7 연결성 검토 완료

    내용: 연결과 \(\R\)의 구간, 중간값 정리, 경로연결(비예: 위상수학자의 사인 곡선), 연결성분, 국소 경로연결, 국소상수함수, \(\R \not\cong \R^n\) · 기준 예제: \(\RP^n\), \(T^2\)(연결)

넘겨주는 것

  • 부분공간 위상, 위상동형사상, 위상 매장 → 6장(정칙곡면의 정의 정의 6.1.1: 매개화는 \(V \cap S\) 위로의 위상동형사상. 이 조건이 없으면 생기는 일: 비예 6.1.3(c)), 14장(매끄러운 매장 = 몰입 + 위상 매장, 8자 곡선 비예 3.3.11)
  • 토러스와 원환면: 예 3.3.17(\(T^2 \cong\) 원환면 \(T_{R,r}\)), 예 3.4.10과 예 3.6.13(\([0,1]^2/{\sim} \cong T^2\)) → 6장(정칙곡면으로서의 원환면: 예 6.5.8), 11장(곱다양체 \(T^2 = S^1 \times S^1\)), 19장
  • \(\RP^n\): 정의 3.4.11, 명제 3.4.14(\(S^n/{\pm} \cong \RP^n\)), 명제 3.4.15(\(\varphi_i\colon U_i \to \R^n\)이 위상동형사상), 명제 3.5.7·명제 3.5.11(하우스도르프, 제2가산), 명제 3.6.14(컴팩트), 예 3.7.10(연결) → 11장(위상다양체임은 이미 증명됨; 남은 일은 좌표변환 \(\varphi_j \circ \varphi_i^{-1}\)의 매끄러움), 18장(방향 불가능성)
  • 하우스도르프 조건과 제2가산 조건, 비예(원점이 두 개인 직선, \(\R \times \R_{\text{이산}}\)) → 11장(위상다양체의 정의)
  • 예 3.2.14(c)(입체사영은 위상동형사상), 곱위상, 몫사상의 특징적 성질 → 11장(\(S^n\)의 차트, 곱다양체, 몫으로 만든 다양체)
  • 2장이 미리 인용한 사실의 증명: 하이네-보렐 정리(정리 3.6.7), 최댓값·최솟값 정리(정리 3.6.10), 균등연속성(따름정리 3.6.19), 중간값 정리(따름정리 3.7.6), 폐포 = 집합 \(\cup\) 경계점(명제 3.1.27) → 2장(2.1절 준비의 (i)–(iii), (v)와 폐포의 약속. 3.6절의 비교 상자에 대응을 적었다)
  • 최댓값·최솟값 정리(정리 3.6.10)와 중간값 정리(따름정리 3.7.6) → 4장(꺾은선 근사의 오차 상한, 접촉원의 접촉 차수 추정, 1변수 역함수 정리, 접선각 함수의 유일성)
  • 컴팩트성: 하이네-보렐 정리, 최댓값 정리, 닫힌사상 보조정리 → 8장(컴팩트 곡면의 타원점), 10장(전역 가우스-보네의 가정), 23장(호프-리노프 정리)
  • 르베그 수 보조정리와 균등연속성 → 5장(접선회전정리의 증명)
  • 린델뢰프 성질 → 12장(단위분할의 존재)
  • 연결성: 정리 3.7.15(국소 경로연결이면 연결 \(\iff\) 경로연결), 명제 3.7.16(국소상수함수), 따름정리 3.7.18(연결인 열린집합에서 \(DF = 0\)이면 상수) → 19장(\(H^0\)과 연결성분), 10장(연결 컴팩트 곡면)
  • 거리공간과 거리 위상, 명제 3.1.25(같은 위상을 주는 거리) → 21장(리만 거리가 다양체의 위상을 준다)
  • 남긴 질문: \(m \ne n\)이면 \(\R^m \not\cong \R^n\)인가? 이 장은 \(\R \not\cong \R^n\)만 증명한다(예 3.7.17). 매끄러운 경우는 13장에서 접공간의 차원으로 답한다.
