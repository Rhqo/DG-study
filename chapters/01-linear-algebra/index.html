1. 선형대수 복습

Part 0. 준비 · 대응 교재: [Ax 1–3, 6, 9장], [Lee-ISM 부록 B], [Lee-IRM 2장, 부록 B], [dC §1-4]

줄기: T6 쌍대성과 텐서 (시작: 쌍대공간, 반변·공변 성분) · T2 미분과 접공간 (준비: 선형사상과 행렬) · T3 내재적 vs 외재적 (준비: 내적과 그람 행렬) · T5 적분과 위상 (준비: 행렬식, 부피, 방향)

이 장의 질문

  • 좌표(기저)를 바꾸면 벡터의 성분과 ‘벡터를 받아 수를 내는 함수’의 성분은 각각 어떻게 바뀌는가?
  • 길이, 각, 부호 있는 부피는 선형대수의 어떤 도구로 표현되는가?

이어받는 것

  • 이 장이 출발점이다. 학부 선형대수(행렬 계산, 연립일차방정식과 가우스 소거법)를 한 번 배웠다고 가정한다. 증명은 모두 이 장 안에서 처음부터 쓴다.
  • 미적분학의 편미분과 곱의 미분법은 예(극좌표 기저, 나선과 구면의 벡터)를 만들 때만 쓴다. 이론 전개에는 쓰지 않는다.

절 목록

  1. 1.1 벡터공간과 기저 검토 완료

    내용: 벡터공간과 부분공간, 생성과 일차독립, 기저와 성분, 교환 보조정리와 차원 · 이 장의 기준 기저 \(\mathcal{B} = ((2,1), (-1,1))\)

  2. 1.2 선형사상과 행렬 검토 완료

    내용: 선형사상, 핵과 상, 차원 정리와 계수, 동형사상과 좌표사상, 기저에 대한 행렬 \([T]^{\mathcal{C}}_{\mathcal{B}}\)(성분 \(A^i_j\))과 합성

  3. 1.3 쌍대공간과 쌍대기저 검토 완료

    내용: 쌍대공간 \(V^*\)와 여벡터(등위선 그림), 쌍대기저 \(\beta^i(b_j) = \delta^i_j\), 쌍대사상 \(T^*\)와 전치, 행 계수 = 열 계수, 이중쌍대 \(V^{**} \cong V\) · 극좌표 기저의 쌍대기저

  4. 1.4 기저변환과 성분변환 검토 완료

    내용: 기저변환 행렬, 반변 성분(\(B^{-1}\))과 공변 성분(\(B\)), 인덱스 위치 규약(비고 1.4.9), \(\sum_i \omega_i v^i\)의 불변성, 행렬의 변환 \(C^{-1}AB\)와 대각합

  5. 1.5 내적과 그람 행렬 검토 완료

    내용: 내적과 노름, 코시-슈바르츠, 유클리드 거리, 그람-슈미트, 그람 행렬 \((g_{ij})\)와 \(B^{\mathsf{T}}GB\), 내적이 주는 동형 \(V \cong V^*\)(첨자 내리기·올리기)

  6. 1.6 행렬식, 방향, 외적 검토 완료

    내용: 교대 다중선형 함수, 행렬식의 존재·유일성과 성질, 그람 행렬식과 부피, 벡터공간의 방향, \(\R^3\)의 외적(쐐기곱과 구별)

넘겨주는 것

  • 선형사상, 행렬 표현, 합성 = 행렬곱(정리 1.2.16), 차원 정리와 계수, 노름과 선형사상의 유계성(명제 1.5.7) → 2장(전미분을 선형사상으로 정의하고 크기를 잰다, 연쇄법칙은 정리 1.2.16의 행렬판)
  • 행렬식과 그 성질(정리 1.6.8), 부피 \(\abs{\det}\)(따름정리 1.6.9) → 2장(역함수 정리의 가정 \(\det DF(p) \neq 0\), 변수변환 공식의 \(\abs{\det DF}\))
  • 극좌표 기저(예 1.3.9, 예 1.4.11), 행렬의 변환(정리 1.4.12), 그람 행렬의 성질(명제 1.5.13), 내적이 주는 동형(명제 1.5.15), 구면의 두 편미분 벡터의 일차독립(연습 1.1.5) → 2장(극좌표 사상의 전미분과 그 역, 선형사상의 표준형과 계수의 반연속성, 기울기, 구면 매개화의 계수 \(2\))
  • 유클리드 거리와 삼각부등식(따름정리 1.5.6(b)) → 3장(거리공간의 열린집합에서 위상으로). “같은 방향” 관계의 반사율·대칭률·추이율과 동치류(명제 1.6.12) → 3장(일반적인 동치관계와 몫집합)
  • 동형사상과 기호 \(\cong\)(정의 1.2.11), 역사상은 저절로 선형(명제 1.2.12), 행렬 표현(명제 1.2.14), 선형사상의 유계성(명제 1.5.7), 행렬식(정의 1.6.6) → 3장(위상동형사상과의 비교, 선형사상의 연속성, \(\GL(n, \R)\)은 열려 있고 연결이 아니다)
  • 내적, 노름·직교, 각, 외적과 곱의 미분법(1.6절 끝), 코시-슈바르츠 부등식(정리 1.5.5), 정규직교기저에서의 계산(명제 1.5.9) → 4장(속도, 길이, 곡률의 계산)
  • 평면의 회전 \(R_\alpha\)(예 1.2.2), 행렬식과 방향 → 4장(부호곡률의 \(J = R_{\pi/2}\)와 부호, 평면의 강체운동)
  • 외적의 성질(정리 1.6.16), 양의 정규직교기저의 외적(명제 1.6.17), 나선의 \(\gamma' \times \gamma''\)(연습 1.6.2) → 5장(종법선벡터 \(\mathbf{b} = \mathbf{t} \times \mathbf{n}\)과 곡률·비틀림률 공식)
  • 부분공간, 기저, 차원, 구면의 두 편미분 벡터의 일차독립(연습 1.1.5) → 6장(접평면은 \(\R^3\)의 2차원 부분공간: 명제 6.2.4. 구면의 기준 매개화: 예 6.1.7)
  • 그람 행렬과 그 변환(명제 1.5.13), 그람 행렬식, 외적과 넓이(정리 1.6.16(d)), 방향과 법벡터로 평면의 방향 정하기(연습 1.6.7(b)), 구면의 그람 행렬과 외적(연습 1.5.2, 연습 1.6.3) → 7장(\(E, F, G\), \(EG - F^2 = \abs{\mathbf{x}_u \times \mathbf{x}_v}^2\), 단위법벡터와 곡면의 방향)
  • 대각합과 행렬식의 기저 무관성 → 8장(\(H = \tfrac12\tr W_p\), \(K = \det W_p\))
  • 기저변환 행렬, 반변 성분의 변환(정리 1.4.5), 인덱스 위치 규약(비고 1.4.9), 극좌표 기저(예 1.4.11) → 13장(접벡터 성분의 변환 법칙, 합 규약)
  • 쌍대공간과 여벡터, 쌍대기저(정리 1.3.5), 공변 성분의 변환(정리 1.4.6), 쌍대사상(명제 1.3.11), 다중선형 → 16장(여접공간, 좌표 1-형식 \(dx^i\), 당김, 텐서)
  • 교대 다중선형 함수(보조정리 1.6.2)와 행렬식의 유일성(정리 1.6.5), 치환의 부호 \(s(\sigma) = \det P_\sigma\)와 전개식 (1.6.5)(정리 1.6.8(c)의 증명) → 17장(쐐기곱의 결정식 규약. 17장은 \(s(\sigma)\)를 \(\sgn\sigma\)로 쓰고 이 정의를 상기한다)
  • 벡터공간의 방향(명제 1.6.12) → 18장(다양체의 방향)
  • 내적이 주는 동형 \(V \cong V^*\)(명제 1.5.15), 그람-슈미트, 그람 행렬식 \(\sqrt{\det G}\) → 21장(음악적 동형과 기울기, 정규직교 틀, 체적형식)
