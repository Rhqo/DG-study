7.4 Conformal Maps

References: [dC §4-2]

Goals

  • conformal map과 local conformal map을 정의하고, 그것이 곡선 사이의 각을 보존하는 map과 같음을 증명할 수 있다.
  • \(E, F, G\)가 비례하는지로 conformality를 판정하고, isothermal parametrization을 알아볼 수 있다.
  • stereographic projection과 Mercator projection이 conformal임을 보이고, conformal map·넓이를 보존하는 map·isometry의 관계를 설명할 수 있다.

Prerequisites

  • Definition 7.1.11 (angle between curves), (7.1.7), Example 7.1.6 (surface of revolution, catenoid)
  • Definition 7.2.4 (local isometry), Theorem 7.2.7 (criterion by \(E, F, G\)), Non-example 7.2.10
  • Example 7.3.12 (Archimedes' projection), Exercise 7.3.7
  • Definition 6.3.5 (surface 위의 smooth function), Theorem 6.4.11 (inverse function theorem for surfaces), Exercise 6.1.5 (stereographic projection의 inverse map)
  • Example 3.2.14(c) (stereographic projection), Theorem 1.5.10 (Gram–Schmidt process)

Motivation

Section 7.3은 Archimedes' projection으로 끝났다. sphere를 cylinder로, 곧 평면으로 펼 때 넓이는 그대로 옮길 수 있지만 모양은 찌그러진다. 항해에 쓰는 지도는 사정이 반대다. 배가 나침반이 가리키는 한 방향, 곧 meridian과 일정한 각을 유지하며 가는 항로를 지도 위에 직선으로 그리고 싶다. 그러려면 지도가 각을 보존해야 한다. 넓이는 틀려도 된다.

Section 7.2의 두 예가 실마리다. 닮음 \(p \mapsto \lambda p\)는 모든 길이를 \(\lambda\)배 하므로 각을 보존한다(Non-example 7.2.3(a)). exponential map \((e^x\cos y, e^x\sin y)\)는 점마다 다른 배율 \(e^x\)로 길이를 늘이지만, 한 점에서는 모든 방향을 같은 배율로 늘인다(Non-example 7.2.10). “한 점에서 모든 방향의 길이를 같은 배율로 바꾸는 map”이 각을 보존하는 map이라는 것이 이 절의 첫 정리다.

Exercise 6.1.5에서 stereographic projection의 inverse map \(\sigma^{-1}\)의 두 partial derivative가 서로 수직이고 길이가 같다는 것을 계산했다. 그것이 “stereographic projection은 각을 보존한다”는 뜻이었음을 여기서 확인한다.

Intuition: 격자의 직각은 그대로, 칸의 크기만 바뀐다

Figure 7.4.1은 평면의 정사각형 격자를 \(\sigma^{-1}\)로 sphere에 옮긴 것이다. 직선은 북극 \(e_3 = (0, 0, 1)\)을 지나는 원이 되지만, 두 격자선이 만나는 각은 여전히 직각이다. 작은 정사각형 \(Q\)는 작은 “굽은 정사각형”이 된다. 모양은 거의 그대로이고 크기만 점마다 다른 배율로 바뀐다. 이것이 conformal map이다.

Conformal Maps

이 절에서도 \(S_1, S_2\)는 regular surface이고 \(O \subseteq S_1\)은 open set이다.

Definition 7.4.1 (conformal map). diffeomorphism \(\varphi\colon S_1 \to S_2\)와 smooth function \(\lambda\colon S_1 \to (0, \infty)\)가 모든 \(p \in S_1\), \(w_1, w_2 \in T_pS_1\)에 대하여

\[ \inner{d\varphi_p(w_1)}{d\varphi_p(w_2)} = \lambda(p)^2\,\inner{w_1}{w_2} \tag{7.4.1} \]

를 만족하면 \(\varphi\)를 conformal map(등각사상)이라 하고 \(S_1\)과 \(S_2\)가 conformal이라 한다. diffeomorphism을 요구하지 않고, smooth map \(\varphi\colon O \to S_2\)와 smooth \(\lambda\colon O \to (0, \infty)\)가 모든 \(p \in O\)에서 (7.4.1)을 만족하면 \(\varphi\)를 local conformal map(국소 등각사상)이라 한다.

\(\lambda(p)\)는 \(p\)에서 길이의 배율이다. (7.4.1)에서 \(w_1 = w_2 = w\)로 두면 \(\abs{d\varphi_p(w)} = \lambda(p)\abs{w}\)이므로 배율은 방향에 무관하고, 점에 따라서만 달라진다. \(\lambda \equiv 1\)이면 (local) isometry이다. \(\lambda(p) \gt 0\)이므로 \(d\varphi_p\)는 injective이고, 따라서 local conformal map은 모든 점에서 local diffeomorphism이다(Theorem 6.4.11, Proposition 7.2.5(a)와 같은 논법).

Example 7.4.2 (examples of conformal maps). (a) local isometry는 \(\lambda \equiv 1\)인 local conformal map이다. isometry는 conformal map이다.

(b) 닮음 \(\varphi(p) = cp\) (\(c \gt 0\))는 \(S^2(r)\)에서 \(S^2(cr)\) 위로 가는 conformal map이고 \(\lambda \equiv c\)이다. \(d\varphi_p(w) = cw\)이기 때문이다.

(c) exponential map \(\psi(x, y, 0) = (e^x\cos y,\ e^x\sin y,\ 0)\)(Example 6.4.12)는 평면에서 평면으로 가는 local conformal map이고 \(\lambda(x, y, 0) = e^x\)이다. Non-example 7.2.10에서 \(\psi \circ \iota\)의 coefficient가 \(e^{2u}\,(1, 0, 1)\)임을 보았으므로, \(w = a\,\iota_u + b\,\iota_v\)이면 \(\abs{d\psi(w)}^2 = e^{2u}(a^2 + b^2) = e^{2u}\abs{w}^2\)이다(편극 논법으로 inner product도 그렇다). \(\psi\)는 injective가 아니므로 conformal map은 아니다.

Non-example 7.4.3 (map with direction-dependent scaling). 평면의 늘이기 \(\varphi(x, y, 0) = (2x, y, 0)\)은 diffeomorphism이지만 conformal map이 아니다. \(d\varphi_p(e_1) = 2e_1\), \(d\varphi_p(e_2) = e_2\)이므로 배율이 방향에 따라 \(2\)와 \(1\)로 다르다. 그 결과 각도 바뀐다. \(e_1\)과 \(e_1 + e_2\) 사이의 각 \(\pi/4\)가 \(2e_1\)과 \(2e_1 + e_2\) 사이의 각 \(\arctan(1/2) \approx 26.6^\circ\)이 된다.

“배율이 방향에 무관하다”와 “각을 보존한다”가 같다는 것은 linear algebra의 사실이다. 흥미롭게도 직각만 보존해도 충분하다.

Proposition 7.4.4 (linear maps preserving angles). \(V, W\)가 2-dimensional inner product space이고 \(T\colon V \to W\)가 injective인 linear map이라 하자. 다음은 서로 동치다.

  • (a) 어떤 \(c \gt 0\)이 있어 모든 \(v, w \in V\)에서 \(\inner{Tv}{Tw} = c^2\inner{v}{w}\)이다.
  • (b) \(0\)이 아닌 모든 \(v, w \in V\)에서 \(Tv\)와 \(Tw\) 사이의 각은 \(v\)와 \(w\) 사이의 각과 같다.
  • (c) \(\inner{v}{w} = 0\)이면 \(\inner{Tv}{Tw} = 0\)이다. 곧 \(T\)는 orthogonality를 보존한다.

Proof idea: orthonormal basis \((e_1, e_2)\)를 잡으면 (c)에서 \(Te_1 \perp Te_2\)이다. 한편 \(e_1 + e_2\)와 \(e_1 - e_2\)도 orthogonal이므로 그 image도 orthogonal이고, 이것이 \(\abs{Te_1} = \abs{Te_2}\)를 준다.

Proof. (a) ⇒ (b): \(\dfrac{\inner{Tv}{Tw}}{\abs{Tv}\abs{Tw}} = \dfrac{c^2\inner{v}{w}}{c\abs{v}\,c\abs{w}} = \dfrac{\inner{v}{w}}{\abs{v}\abs{w}}\)이고, 각은 이 코사인으로 정해진다(Corollary 1.5.6(c)). \(T\)가 injective이므로 \(Tv, Tw \neq 0\)이다. (b) ⇒ (c): \(v\) 또는 \(w\)가 \(0\)이면 분명하다. 둘 다 \(0\)이 아니고 orthogonal이면 사이의 각이 \(\pi/2\)이므로 \(Tv\)와 \(Tw\)의 각도 \(\pi/2\)다.

(c) ⇒ (a): Gram–Schmidt process(Theorem 1.5.10)으로 \(V\)의 orthonormal basis \((e_1, e_2)\)를 잡는다. (c)에서 \(\inner{Te_1}{Te_2} = 0\)이다. 또 \(\inner{e_1 + e_2}{e_1 - e_2} = \abs{e_1}^2 - \abs{e_2}^2 = 0\)이므로

\[ \begin{aligned} 0 = \inner{T(e_1 + e_2)}{T(e_1 - e_2)} &= \abs{Te_1}^2 - \inner{Te_1}{Te_2} + \inner{Te_2}{Te_1} - \abs{Te_2}^2\\ &= \abs{Te_1}^2 - \abs{Te_2}^2 \end{aligned} \]

이다. \(c = \abs{Te_1} = \abs{Te_2}\)로 두면 \(T\)가 injective이므로 \(c \gt 0\)이다. \(v = v^1e_1 + v^2e_2\), \(w = w^1e_1 + w^2e_2\)이면 bilinearity에서

\[ \inner{Tv}{Tw} = \sum_{i,j} v^iw^j\inner{Te_i}{Te_j} = c^2(v^1w^1 + v^2w^2) = c^2\inner{v}{w} \]

이다(마지막 등호는 orthonormal basis에서의 계산, Proposition 1.5.9).

Theorem 7.4.5 (local conformal maps preserve angles). \(\varphi\colon O \to S_2\)가 매끄럽고 모든 \(p \in O\)에서 \(d\varphi_p\)가 injective라 하자. \(\varphi\)가 local conformal map일 필요충분조건은 다음이다. \(O\) 안의 두 regular curve \(\alpha, \beta\)가 \(p\)에서 각 \(\vartheta\)를 이루면(Definition 7.1.11), regular curve \(\varphi \circ \alpha\), \(\varphi \circ \beta\)도 \(\varphi(p)\)에서 각 \(\vartheta\)를 이룬다.

이 정리가 말하는 것. “각을 보존한다”는 기하적인 성질과 “미분이 inner product를 한 배율로 늘인다”는 대수적인 성질은 같다. 다만 각을 보존하는 map에서도 배율 \(\lambda\)가 매끄럽다는 것을 따로 확인해야 한다.

Proof. \(\alpha(t_0) = p\)이면 Proposition 7.2.6의 증명처럼 \((\varphi \circ \alpha)'(t_0) = d\varphi_p(\alpha'(t_0))\)이고, \(d\varphi_p\)가 injective이므로 \(\varphi \circ \alpha\)는 regular이다. \(\beta\)도 같다.

(⇒) \(d\varphi_p\)는 (7.4.1)에 의해 Proposition 7.4.4(a)를 만족하므로 (b)에 의해 \(\alpha'(t_0)\), \(\beta'(s_0)\) 사이의 각을 보존한다.

(⇐) \(p \in O\)와 \(0\)이 아닌 \(w_1, w_2 \in T_pS_1\)을 잡자. \(p\) 근처의 parametrization \(\mathbf{x}\)(\(\mathbf{x}(q) = p\), \(\mathbf{x}(U) \subseteq O\))로 \(w_i = D\mathbf{x}(q)(a_i, b_i)\)라 쓰면 \(\alpha_i(t) = \mathbf{x}(q + t(a_i, b_i))\)는 \(\alpha_i'(0) = w_i\)인 regular curve이다. 가정에서 \(d\varphi_p(w_1)\)과 \(d\varphi_p(w_2)\)의 각은 \(w_1\)과 \(w_2\)의 각과 같으므로 \(d\varphi_p\)는 Proposition 7.4.4(b)를 만족하고, (a)의 \(c = c(p) \gt 0\)이 있다. \(\lambda(p) = c(p)\)로 두면 (7.4.1)이 성립한다. 남은 것은 \(\lambda\)가 매끄럽다는 것이다. \(\mathbf{y} = \varphi \circ \mathbf{x}\)라 하면 Theorem 7.2.7(a)에서 \(\mathbf{y}_u = d\varphi(\mathbf{x}_u)\)이므로

\[ \lambda\big(\mathbf{x}(q')\big)^2 = \frac{\abs{d\varphi(\mathbf{x}_u)}^2}{\abs{\mathbf{x}_u}^2} = \frac{\inner{\mathbf{y}_u}{\mathbf{y}_u}}{E}(q') \qquad (q' \in U) \]

이다. 우변은 \(U\)에서 매끄럽고 양수이므로 \(\lambda \circ \mathbf{x}\)는 매끄럽다(양수의 제곱근). \(O\)의 모든 점이 이런 \(\mathbf{x}(U)\)에 들어 있으므로 \(\lambda\)는 smooth 함수다(Definition 6.3.5).

The Criterion by \(E, F, G\) and Isothermal Parametrizations

Theorem 7.2.7과 같은 판정이 conformal map에도 있다. “coefficient가 같다” 대신 “coefficient가 비례한다”가 된다.

Theorem 7.4.6 (criterion for local conformality by \(E, F, G\)). \(\varphi\colon O \to S_2\)가 매끄럽다고 하자. \(\mathbf{x}(U) \subseteq O\)인 parametrization \(\mathbf{x}\)에 대하여 \(\mathbf{y} = \varphi \circ \mathbf{x}\)로 둔다. 다음은 서로 동치다.

  • (i) \(\varphi\)는 local conformal map이다.
  • (ii) 모든 \(p \in O\)에 대하여 \(p \in \mathbf{x}(U) \subseteq O\)인 parametrization \(\mathbf{x}\)와 smooth \(\mu\colon U \to (0, \infty)\)가 있어서 \(U\)에서
\[ \big(\inner{\mathbf{y}_u}{\mathbf{y}_u},\ \inner{\mathbf{y}_u}{\mathbf{y}_v},\ \inner{\mathbf{y}_v}{\mathbf{y}_v}\big) = \mu\,(E, F, G) \tag{7.4.2} \]
  • (iii) \(\mathbf{x}(U) \subseteq O\)인 모든 parametrization \(\mathbf{x}\)에 대하여 (7.4.2)인 smooth \(\mu \gt 0\)이 있다.

이때 \(\mu = \lambda^2 \circ \mathbf{x}\)이다. 특히 같은 정의역의 두 parametrization \(\mathbf{x}\colon U \to S_1\), \(\mathbf{y}\colon U \to S_2\)의 coefficient가 smooth \(\mu \gt 0\)에 대해 \((\bar E, \bar F, \bar G) = \mu(E, F, G)\)이면 \(\mathbf{y} \circ \mathbf{x}^{-1}\colon \mathbf{x}(U) \to \mathbf{y}(U)\)는 conformal map이다.

Proof. (i) ⇒ (iii): Theorem 7.2.7(a)와 (7.4.1)에서 \(\inner{\mathbf{y}_u}{\mathbf{y}_u} = \inner{d\varphi(\mathbf{x}_u)}{d\varphi(\mathbf{x}_u)} = (\lambda \circ \mathbf{x})^2 E\)이고, \(F, G\)도 같다. \(\mu = \lambda^2 \circ \mathbf{x}\)는 \(\lambda\)가 매끄러우므로 매끄럽다(Proposition 6.3.6). (iii) ⇒ (ii)는 Theorem 7.2.7의 증명과 같다.

(ii) ⇒ (i): \(p = \mathbf{x}(q)\), \(w = a\,\mathbf{x}_u + b\,\mathbf{x}_v\)이면 \(d\varphi_p(w) = a\,\mathbf{y}_u + b\,\mathbf{y}_v\)이므로 \(\abs{d\varphi_p(w)}^2 = \mu(q)(Ea^2 + 2Fab + Gb^2) = \mu(q)\abs{w}^2\)이다. 편극 논법(Definition 7.2.1 뒤)에서 \(\inner{d\varphi_p w_1}{d\varphi_p w_2} = \mu(q)\inner{w_1}{w_2}\)이다. \(\lambda(p) = \abs{d\varphi_p(w)}/\abs{w}\)(\(w \neq 0\))로 두면 이 값은 parametrization을 쓰지 않고 정해지므로 \(O\) 전체에서 잘 정의된 함수이고, \(\lambda \circ \mathbf{x} = \sqrt{\mu}\)가 매끄러우므로 \(\lambda\)는 매끄럽다. 따라서 \(\varphi\)는 local conformal map이다. 마지막 주장: \(\mathbf{y} \circ \mathbf{x}^{-1}\)은 diffeomorphism이고(Corollary 7.2.8(a)의 증명과 같다) (ii)를 만족하므로 conformal map이다.

가장 간단한 경우는 parametrization 자체가 평면에서 가는 conformal map인 경우다. Example 6.3.12(b)처럼 \(U\)를 평면 조각 \(\tilde U = U \times \{0\}\)(coefficient \((1, 0, 1)\))으로 보면, Theorem 7.4.6에서 \(\tilde{\mathbf{x}}\colon \tilde U \to \mathbf{x}(U)\)가 conformal map일 필요충분조건은 \((E, F, G) = \mu\,(1, 0, 1)\)이다.

Definition 7.4.7 (isothermal parametrization). parametrization \(\mathbf{x}\colon U \to S\)가 \(U\)에서 \(E = G\), \(F = 0\)을 만족하면 \(\mathbf{x}\)를 isothermal parametrization(등온 매개화)라 한다.

isothermal parametrization에서는 \(\mathrm{I}_p(a\,\mathbf{x}_u + b\,\mathbf{x}_v) = E\,(a^2 + b^2)\)이다. 곧 좌표평면의 각이 surface 위의 각과 같고, 길이는 점마다 배율 \(\sqrt{E}\)만 곱해진다. Exercise 7.1.7에서 본 “좌표 칸이 작은 정사각형에 가깝다”는 조건이 모든 점에서 성립하는 것이다.

Example 7.4.8 (examples and non-examples of isothermal parametrizations). (a) 평면의 \(\iota(u, v) = (u, v, 0)\)은 \(E = G = 1\), \(F = 0\)이므로 isothermal이다. polar coordinates parametrization은 \(E = 1\), \(G = \rho^2\)이므로(Example 7.1.8) \(\rho \neq 1\)인 곳에서 isothermal이 아니다.

(b) catenoid의 parametrization \((\cosh u\cos v,\ \cosh u\sin v,\ u)\)는 \(E = G = \cosh^2 u\), \(F = 0\)이므로(Example 7.1.6(d)) isothermal이다. 따라서 평면의 띠 \(\R \times (a, a + 2\pi)\)에서 catenoid 위로 가는 conformal map이 있다. helicoid의 \(\mathbf{y}\)(Exercise 7.1.6)도 같은 coefficient를 가지므로 isothermal이다.

(c) sphere의 standard parametrization은 \(E = r^2 \neq r^2\sin^2\theta = G\)(적도 밖)이므로 isothermal이 아니다. cylinder의 standard parametrization도 \(r \neq 1\)이면 \(E = r^2 \neq 1 = G\)이다. 그러나 cylinder는 \((r\cos(s/r), r\sin(s/r), v)\)로 parametrization을 다시 잡으면 \(E = G = 1\)이 된다(Example 7.2.9). sphere의 isothermal parametrization은 다음 두 예에서 만든다.

Stereographic Projection and Mercator Projection

Example 7.4.9 (stereographic projection is conformal). unit sphere \(S^2 = S^2(1)\)과 북극 \(e_3 = (0, 0, 1)\)에 대해, running example의 stereographic projection(Example 3.2.14(c))을 평면 \(P = \{z = 0\}\)으로 가는 map으로 보자.

\[ \sigma\colon S^2 \setminus \{e_3\} \to P, \qquad \sigma(x, y, z) = \Big(\frac{x}{1 - z},\ \frac{y}{1 - z},\ 0\Big) \]

\(\sigma\)는 open set \(\{z \neq 1\}\) 위의 smooth map의 제한이므로 매끄럽고, inverse map \(\sigma^{-1}(u, v, 0) = \dfrac{(2u,\ 2v,\ u^2 + v^2 - 1)}{u^2 + v^2 + 1}\)도 \(\R^3\)의 smooth map의 제한이므로 매끄럽다(Example 6.3.12(a)). 곧 \(\sigma\)는 diffeomorphism이다. \(\mathbf{y} = \sigma^{-1} \circ \iota\), \(w = u^2 + v^2 + 1\)이라 하면 Exercise 6.1.5에서 계산한 대로

\[ \mathbf{y}_u = \frac{2}{w^2}\big(1 - u^2 + v^2,\ -2uv,\ 2u\big), \qquad \mathbf{y}_v = \frac{2}{w^2}\big(-2uv,\ 1 + u^2 - v^2,\ 2v\big) \]

이고 \(\inner{\mathbf{y}_u}{\mathbf{y}_v} = 0\), \(\abs{\mathbf{y}_u}^2 = \abs{\mathbf{y}_v}^2 = 4/w^2\)이다. 곧

\[ E = G = \frac{4}{(1 + u^2 + v^2)^2}, \qquad F = 0 \tag{7.4.3} \]

이므로 \(\mathbf{y}\)는 sphere에서 북극을 뺀 부분의 isothermal parametrization이고, Theorem 7.4.6에 의해 \(\sigma^{-1}\colon P \to S^2 \setminus \{e_3\}\)은 \(\lambda = 2/(1 + u^2 + v^2)\)인 conformal map이다. 그 inverse map \(\sigma\)도 conformal map이고(Exercise 7.4.4) 배율은 \((1 + u^2 + v^2)/2\)이다. sphere의 점 \(p = (x, y, z)\)로 쓰면 \(1 - z = 2/(1 + u^2 + v^2)\)이므로 \(\sigma\)의 배율은 \(\lambda_\sigma(p) = 1/(1 - z)\)이다. 남극에서는 \(1/2\)이고 북극으로 갈수록 한없이 커진다(Figure 7.4.1). 북극 근처는 남극에서의 stereographic projection으로 같은 계산을 하면 된다. 따라서 sphere는 모든 점 근처에서 평면과 conformal이다.

stereographic projection은 극 하나를 뺀 sphere 전체를 평면 하나로 옮기지만, meridian과 circle of latitude는 원점을 지나는 직선과 원점 중심의 원이 된다. 항해에는 meridian이 평행한 세로선이 되는 지도가 편하다. 이런 지도를 만들려면 가로 좌표를 경도 \(\varphi\)로 두고, 세로 좌표 \(t(\theta)\)를 등각이 되게 고르면 된다.

Example 7.4.10 (Mercator projection). sphere \(S^2(r)\)에서 반원 \(C\)를 뺀 부분 \(\mathbf{x}(U)\)에서 평면으로 가는 map \(\psi\)를 \(\psi(\mathbf{x}(\theta, \varphi)) = (\varphi,\ t(\theta),\ 0)\)으로 찾자. \(\mathbf{y} = \psi \circ \mathbf{x} = (\varphi, t(\theta), 0)\)이면 \(\mathbf{y}_\theta = (0, t'(\theta), 0)\), \(\mathbf{y}_\varphi = (1, 0, 0)\)이므로 coefficient는 \(\big((t')^2,\ 0,\ 1\big)\)이다. sphere의 coefficient는 \((r^2, 0, r^2\sin^2\theta)\)(Example 7.1.2)이므로, (7.4.2)의 비례 조건 \((t')^2/r^2 = 1/(r^2\sin^2\theta)\)은 \(t' = \pm 1/\sin\theta\)와 같다. 북쪽이 위로 가게 \(t' = -1/\sin\theta\)를 고르면

\[ t(\theta) = \log\cot\frac{\theta}{2}, \qquad \psi\big(\mathbf{x}(\theta, \varphi)\big) = \Big(\varphi,\ \log\cot\frac{\theta}{2},\ 0\Big) \tag{7.4.4} \]

이다. 실제로 \(\tfrac{d}{d\theta}\log\cot\tfrac\theta2 = -\dfrac{\csc^2(\theta/2)}{2\cot(\theta/2)} = -\dfrac{1}{2\sin(\theta/2)\cos(\theta/2)} = -\dfrac{1}{\sin\theta}\)이다. \(t\)는 \((0, \pi)\)에서 \(\R\) 위로 가는 순감소 diffeomorphism(역함수 \(\theta = 2\arctan e^{-t}\))이므로 \(\mathbf{y}\)는 띠 \((0, 2\pi) \times \R\)의 parametrization이다. coefficient는 \(\mu = 1/(r^2\sin^2\theta)\)에 대해 \(\mu\,(r^2, 0, r^2\sin^2\theta)\)이므로, Theorem 7.4.6에 의해 \(\psi\)는 \(\mathbf{x}(U)\)에서 띠 위로 가는 conformal map이고 배율은 \(\lambda = 1/(r\sin\theta)\)이다. 적도(\(\theta = \pi/2\))에서 배율은 \(1/r\)이고, 극으로 갈수록 한없이 커진다. Mercator projection에서 극지방이 크게 부풀어 보이는 이유다(Figure 7.4.2). meridian과 일정한 각을 이루는 곡선(loxodrome)은 지도에서 직선이 된다. conformal map이 각을 보존하고(Theorem 7.4.5) meridian의 image가 세로선이기 때문이다.

Non-example 7.4.11 (Archimedes' projection is not conformal). Example 7.3.12의 투영 \(\psi\)는 \(\psi \circ \mathbf{x}\)의 coefficient가 \((r^2\sin^2\theta,\ 0,\ r^2)\)이다. sphere의 coefficient \((r^2, 0, r^2\sin^2\theta)\)와 비교하면 \(\bar E/E = \sin^2\theta\), \(\bar G/G = 1/\sin^2\theta\)이므로, 적도 밖에서는 (7.4.2)를 만족하는 \(\mu\)가 없다. Mercator projection은 반대로 각을 보존하지만 area element를 \(\lambda^2 = 1/(r^2\sin^2\theta)\)배 한다.

Conventions

Definition 7.4.1은 do Carmo의 정의와 같다 [dC §4-2 Definition 3]. do Carmo는 local conformal map을 “neighborhood 사이의 conformal map”으로 정의하는데, 이 study set은 Section 7.2와 같이 점마다의 조건으로 정의했다(둘이 같은 이유는 Proposition 7.2.5(a)와 같다). Theorem 7.4.6의 마지막 주장은 do Carmo가 증명을 연습으로 남긴 명제 [dC §4-2 Proposition 2]이고, 각의 보존으로의 특징(Theorem 7.4.5)도 do Carmo에서는 연습문제다 [dC §4-2 Exercise 14]. stereographic projection의 conformality(Example 7.4.9)도 do Carmo에서는 연습문제다 [dC §4-2 Exercise 4]. Mercator projection(Example 7.4.10)도 연습문제로 나오는데 [dC §4-2 Exercise 16], 세로 좌표를 \(\log\tan(\theta/2)\)로 두므로 이 절의 \(t = \log\cot(\theta/2)\)와 부호가 반대다. do Carmo는 또 “임의의 두 regular surface는 locally conformal이다”라는 정리를 증명 없이 소개한다 [dC §4-2 Theorem]. 모든 regular surface가 각 점 근처에서 isothermal parametrization을 갖는다는 것이 핵심인데, partial differential equation의 도구가 필요하므로 이 study set에서도 증명하지 않고, 이후의 증명에 쓰지 않는다.

Looking ahead: 왜곡 없는 세계지도는 없다

sphere에서 평면으로 가는 conformal map(stereographic projection, Mercator projection)도, 넓이를 보존하는 map(Archimedes)도 있다. 두 성질을 동시에 가지면 isometry이다(Exercise 7.4.3). 그런데 Chapter 9의 Theorema Egregium은 sphere의 어떤 열린 부분도 평면과 locally isometric이 아님을 보인다. 따라서 어떤 세계지도도 각과 넓이 가운데 적어도 하나를 왜곡한다. 또 Chapter 9의 hyperbolic plane \(\mathbb{U}^2\)는 처음부터 \(E = G = 1/y^2\), \(F = 0\), 곧 isothermal parametrization의 형태로 주어진다. 평면과 conformal이지만 curvature가 \(-1\)인 “surface”이다. Chapter 21에서 이것을 Riemannian metric \(\breve g\)로 다시 정의한다.

Summary

  • (local) conformal map은 미분이 inner product를 점마다의 배율 \(\lambda(p)^2\)로 바꾸는 map이다. \(\lambda \equiv 1\)이면 (local) isometry이다(Definition 7.4.1).
  • 2-dimensional inner product space 사이의 injective linear map에서 “inner product를 상수배”, “각을 보존”, “orthogonal을 보존”은 모두 같다(Proposition 7.4.4). 그래서 local conformal map은 곡선 사이의 각을 보존하는 map이다(Theorem 7.4.5).
  • \(\varphi\)가 local conformal map일 필요충분조건은 \(\varphi \circ \mathbf{x}\)의 coefficient가 \(\mathbf{x}\)의 coefficient에 비례하는 것이다(Theorem 7.4.6). \(E = G\), \(F = 0\)인 parametrization이 isothermal parametrization이다.
  • stereographic projection은 conformal이고 배율은 \(1/(1 - z)\)이다. Mercator projection \((\varphi, \log\cot(\theta/2))\)는 conformal이고 loxodrome을 직선으로 보낸다. Archimedes' projection은 넓이를 보존하지만 conformal이 아니다.

다음 절에서는 surface의 “앞면과 뒷면”을 다룬다. 각 점의 tangent plane에 수직인 단위벡터는 두 개다. surface 전체에서 한쪽을 연속적으로 고를 수 있는가? Möbius strip에서는 그럴 수 없다는 것을 보게 된다.

Exercise 7.4.1 ★ 참인지 거짓인지 판별하고 이유를 대어라. (a) conformal map은 넓이를 보존한다. (b) isothermal parametrization \(\mathbf{x}\colon U \to S\)는 평면 조각 \(\tilde U\)에서 \(\mathbf{x}(U)\) 위로 가는 conformal map을 준다. (c) local conformal map의 배율이 모든 점에서 \(1\)이면 local isometry이다. (d) smooth map \(\varphi\colon O \to S_2\)가 \(O\) 안의 모든 regular curve를 regular curve로 보내고 곡선 사이의 각을 보존하면 local conformal map이다.

Solution

(a) 거짓. 닮음 \(p \mapsto 2p\)는 넓이를 \(4\)배 한다. 일반적으로 area element는 \(\lambda^2\)배가 된다(Exercise 7.4.3의 풀이).

(b) 참. Theorem 7.4.6 뒤의 설명에서 \(\mu = E\)이다.

(c) 참. (7.4.1)이 (7.2.1)이 된다.

(d) 참. \(d\varphi_p(w) = 0\)인 \(w \neq 0\)이 있다면 \(\alpha'(0) = w\)인 regular curve \(\alpha\)에 대해 \((\varphi \circ \alpha)'(0) = d\varphi_p(w) = 0\)이므로 \(\varphi \circ \alpha\)가 regular가 아니다. 따라서 \(d\varphi_p\)는 injective이고 Theorem 7.4.5를 쓸 수 있다. “regular curve를 regular curve로” 보내는 조건은 빠질 수 없다. 평면의 \((u, v, 0) \mapsto (u^2 - v^2,\ 2uv,\ 0)\)은 원점 밖에서는 local conformal map이지만(Exercise 7.4.7) 원점에서 미분이 \(0\)이다. 그래서 원점을 지나는 regular curve의 image는 원점에서 속도가 \(0\)이 되어 각이 정의되지 않고(image의 접선 방향으로 재면 두 반직선 사이의 각이 두 배가 된다), 이 map은 원점을 포함하는 어떤 open set에서도 local conformal map이 아니다.

Exercise 7.4.2 ★ 평면의 “로그 polar coordinates” \(\mathbf{z}(s, \varphi) = (e^s\cos\varphi,\ e^s\sin\varphi,\ 0)\), \((s, \varphi) \in \R \times (0, 2\pi)\)가 isothermal parametrization임을 보여라. polar coordinates parametrization \((\rho, \varphi)\)와 어떻게 관련되는가?

Solution

\(\mathbf{z}_s = e^s(\cos\varphi, \sin\varphi, 0)\), \(\mathbf{z}_\varphi = e^s(-\sin\varphi, \cos\varphi, 0)\)이므로 \(E = G = e^{2s}\), \(F = 0\)이다. \(\mathbf{z}\)는 polar coordinates parametrization \(\mathbf{y}(\rho, \varphi)\)에 diffeomorphism \((s, \varphi) \mapsto (e^s, \varphi)\)를 합성한 것이므로 parametrization이다. Proposition 7.1.7로 확인하면 \(Dh = \diag(e^s, 1)\)이고 \(Dh^{\mathsf{T}}\diag(1, \rho^2)Dh = \diag(e^{2s},\ e^{2s})\)이다(\(\rho = e^s\)). \(\rho = e^s\)로 바꾸면 반지름 방향의 눈금이 \(\rho\)에 비례해 늘어나 각 방향의 눈금과 맞게 된다. \(\mathbf{z}\)는 Example 7.4.2(c)의 exponential map과 같은 식이다.

Exercise 7.4.3 ★ (넓이의 배율) \(\psi\colon S_1 \to S_2\)가 배율 \(\lambda\)인 conformal map이고 \(R\)이 \(S_1\)의 coordinate region이면, \(\psi(R)\)는 \(S_2\)의 coordinate region이고 \(A(\psi(R)) = \iint_R \lambda^2\,dA\)임을 보여라. 이것을 써서 (a) 모든 coordinate region의 넓이를 같은 상수 \(c \gt 0\)배 하는 conformal map은 배율이 상수 \(\sqrt{c}\)임을 보이고(\(c = 1\)이면 isometry이다), (b) stereographic projection의 inverse map \(\sigma^{-1}\)(Example 7.4.9)로 닫힌 남쪽 hemisphere \(\{(x, y, z) \in S^2 : z \le 0\}\)의 넓이를 구하여 Example 7.3.10(c)와 비교하여라. [dC §4-2 Exercise 18, modified]

Solution

공식. \(R = \mathbf{x}(Q)\), \(\overline{Q} \subseteq U\)라 하자. \(\psi\)가 diffeomorphism이므로 \(\mathbf{y} = \psi \circ \mathbf{x}\)는 \(S_2\)의 parametrization이고(Exercise 7.3.7의 풀이), \(\psi(R) = \mathbf{y}(Q)\)는 coordinate region이다. Theorem 7.4.6에서 \((\bar E, \bar F, \bar G) = \mu(E, F, G)\), \(\mu = \lambda^2 \circ \mathbf{x}\)이므로 \(\bar E\bar G - \bar F^2 = \mu^2(EG - F^2)\)이고, \(\mu \gt 0\)이므로 \(\sqrt{\bar E\bar G - \bar F^2} = (\lambda^2 \circ \mathbf{x})\sqrt{EG - F^2}\)이다. \(\lambda^2\)은 \(S_1\)에서 연속이므로 (7.3.2), (7.3.3)에서

\[ \begin{aligned} A(\psi(R)) &= \int_Q \sqrt{\bar E\bar G - \bar F^2}\;du\,dv\\ &= \int_Q (\lambda^2 \circ \mathbf{x})\sqrt{EG - F^2}\;du\,dv\\ &= \iint_R \lambda^2\,dA \end{aligned} \]

이다. 곧 area element는 점마다 \(\lambda^2\)배가 된다.

(a) \(q \in U\)와 Exercise 7.3.5의 정사각형 \(Q_\varepsilon\)을 잡으면 가정에서 \(A(\mathbf{y}(Q_\varepsilon)) = c\,A(\mathbf{x}(Q_\varepsilon))\)이다. 양변을 \(\varepsilon^2\)으로 나누고 \(\varepsilon \to 0\)으로 보내면, Exercise 7.3.5를 \(\mathbf{y}\)와 \(\mathbf{x}\)에 각각 써서 \(\mu(q)\sqrt{EG - F^2}\,(q) = c\sqrt{EG - F^2}\,(q)\)를 얻는다. \(\sqrt{EG - F^2} \gt 0\)이므로 \(\lambda(\mathbf{x}(q))^2 = c\)이다. \(S_1\)의 모든 점은 어떤 parametrization의 image에 있으므로 \(\lambda \equiv \sqrt{c}\)이다. 거꾸로 \(\lambda \equiv \sqrt{c}\)이면 공식에서 \(A(\psi(R)) = c\,A(R)\)이다. \(c = 1\)이면 \(\lambda \equiv 1\)이므로 (7.4.1)이 (7.2.1)이 되어 \(\psi\)는 isometry이다. 곧 넓이를 보존하는 conformal map은 isometry이다.

(b) \(\sigma^{-1}\colon P \to S^2 \setminus \{e_3\}\)은 배율 \(\lambda = 2/(1 + u^2 + v^2)\)인 conformal map이다. 닫힌 단위원판 \(\bar D = \{(u, v, 0) : u^2 + v^2 \le 1\}\)은 평면의 parametrization \(\iota\)에 대한 coordinate region이다. \(\sigma^{-1}\)의 셋째 성분 \((u^2 + v^2 - 1)/(u^2 + v^2 + 1)\)은 \(u^2 + v^2 \le 1\)일 때만 \(0\) 이하이고 \(e_3\)은 남쪽 hemisphere에 없으므로, \(\sigma^{-1}(\bar D)\)는 닫힌 남쪽 hemisphere다. 공식과 Example 2.6.10의 polar coordinates 계산에서

\[ \begin{aligned} A(\{z \le 0\}) &= \int_{\bar D} \frac{4}{(1 + u^2 + v^2)^2}\;du\,dv\\ &= \int_0^{2\pi}\int_0^1 \frac{4\rho}{(1 + \rho^2)^2}\;d\rho\,d\varphi\\ &= 2\pi\Big[-\frac{2}{1 + \rho^2}\Big]_0^1 = 2\pi \end{aligned} \]

이다. Example 7.3.10(c)에서 \(r = 1\), \(\theta_1 = \pi/2\), \(\theta_2 = \pi\)로 둔 값 \(2\pi(\cos\tfrac\pi2 - \cos\pi) = 2\pi\)와 같다. 원판의 넓이는 \(\pi\)이므로 평균적으로 두 배가 된 셈이다(\(\lambda^2\)은 원점에서 \(4\), 단위원 위에서 \(1\)).

Exercise 7.4.4 ★ \(\varphi\colon S_1 \to S_2\), \(\chi\colon S_2 \to S_3\)이 배율 \(\lambda_\varphi\), \(\lambda_\chi\)인 conformal map이면 \(\chi \circ \varphi\)와 \(\varphi^{-1}\)도 conformal map이고, 배율이 각각 \((\lambda_\chi \circ \varphi)\,\lambda_\varphi\)와 \(1/(\lambda_\varphi \circ \varphi^{-1})\)임을 보여라.

Solution

chain rule(Theorem 6.4.8)에서 \(\inner{d(\chi \circ \varphi)w_1}{d(\chi \circ \varphi)w_2} = \lambda_\chi(\varphi(p))^2\inner{d\varphi\,w_1}{d\varphi\,w_2} = \lambda_\chi(\varphi(p))^2\lambda_\varphi(p)^2\inner{w_1}{w_2}\)이다. 배율은 smooth 양의 함수의 곱이므로 매끄럽다. inverse map: \(q = \varphi(p)\), \(w_i' = d\varphi_p(w_i)\)이면 \(d(\varphi^{-1})_q = (d\varphi_p)^{-1}\)(Corollary 6.4.9)이므로 \(\inner{d(\varphi^{-1})w_1'}{d(\varphi^{-1})w_2'} = \inner{w_1}{w_2} = \lambda_\varphi(p)^{-2}\inner{w_1'}{w_2'}\)이다. \(1/(\lambda_\varphi \circ \varphi^{-1})\)은 매끄럽다(Proposition 6.3.10(c)). 합성과 inverse map이 diffeomorphism임은 Exercise 6.3.6이다.

Exercise 7.4.5 ★★ (loxodrome) \(0 \lt \vartheta_0 \lt \pi/2\)라 하자. Mercator 평면의 직선 \(s = s_0 + t\tan\vartheta_0\)을 \(\psi^{-1}\)으로 옮긴 곡선이 모든 점에서 meridian과 각 \(\vartheta_0\)을 이룸을 보이고, 적도에서 출발해 북극으로 다가가는 이 곡선의 길이가 \(\pi r/(2\cos\vartheta_0)\)로 유한함을 보여라. 곡선은 북극 둘레를 무한히 돈다. (loxodrome의 방정식은 do Carmo가 다른 방법으로 구한다 [dC §2-5 Example 4].)

Hint

곡선의 parametrization을 \(\theta\)로 잡는다. \(t = \log\cot(\theta/2)\)이므로 \(d\varphi/d\theta = \tan\vartheta_0 \cdot dt/d\theta\)이다.

Solution

각. Mercator 평면에서 직선은 세로선(meridian의 image)과 각 \(\vartheta_0\)을 이룬다. \(\psi^{-1}\)은 conformal map이므로(Exercise 7.4.4) Theorem 7.4.5에 의해 곡선은 meridian과 각 \(\vartheta_0\)을 이룬다.

길이. \(\theta\)를 매개변수로 쓰면 \(t = \log\cot(\theta/2)\), \(dt/d\theta = -1/\sin\theta\)(Example 7.4.10)이므로 \(\varphi(\theta) = s_0 + t(\theta)\tan\vartheta_0\), \(\varphi'(\theta) = -\tan\vartheta_0/\sin\theta\)이다(\(\varphi\)는 \(2\pi\)를 법으로 읽는다). 곡선이 standard parametrization의 image를 여러 번 드나들지만, \(z\)축 둘레로 돌린 parametrization도 같은 coefficient를 가지므로(Example 7.2.2) Proposition 7.1.9를 조각마다 쓸 수 있고,

\[ \abs{\alpha'(\theta)}^2 = E + G\,\varphi'(\theta)^2 = r^2 + r^2\sin^2\theta\cdot\frac{\tan^2\vartheta_0}{\sin^2\theta} = \frac{r^2}{\cos^2\vartheta_0} \]

이다. 속력이 상수이므로 \(\theta\)가 \(\pi/2\)에서 \(\varepsilon\)까지 가는 동안의 길이는 \((\pi/2 - \varepsilon)\,r/\cos\vartheta_0\)이고, \(\varepsilon \to 0\)이면 \(\pi r/(2\cos\vartheta_0)\)이다. 한편 \(\varphi(\theta) \to \infty\)이므로 곡선은 북극 둘레를 무한히 돈다. (meridian과 이루는 각의 코사인을 직접 계산해도 \(\sqrt{E}/\abs{\alpha'} = \cos\vartheta_0\)이다. \(\vartheta_0 = 0\)이면 meridian이고 길이 \(\pi r/2\)로 맞는다.)

Exercise 7.4.6 ★★ stereographic projection \(\sigma\)가 북극을 지나지 않는 sphere 위의 원(sphere와 평면 \(ax + by + cz = d\)의 교집합, \(c \neq d\))을 평면 \(P\)의 원으로 보냄을 보여라. 북극을 지나는 원(\(c = d\))은 어디로 가는가?

Solution

\((x, y, z) = \sigma^{-1}(u, v, 0) = (2u, 2v, u^2 + v^2 - 1)/w\) (\(w = u^2 + v^2 + 1\))를 평면의 방정식에 넣고 \(w\)를 곱하면

\[ \begin{aligned} &2au + 2bv + c(u^2 + v^2 - 1) = d(u^2 + v^2 + 1),\\ &\text{곧}\quad (c - d)(u^2 + v^2) + 2au + 2bv - (c + d) = 0 \end{aligned} \]

이다. \(c \neq d\)이면 \(c - d\)로 나누고 완전제곱하면 \((u + \tfrac{a}{c - d})^2 + (v + \tfrac{b}{c - d})^2 = k\)(\(k\)는 상수) 꼴이다. 원래 원은 점을 둘 이상 가지므로 image도 그렇고, 따라서 \(k \gt 0\)인 원이다. \(c = d\)이면 식이 \(2au + 2bv = 2c\), 곧 직선이 된다. 북극을 지나는 원은 평면의 직선으로 간다(Figure 7.4.1의 격자선이 그 예다). conformality와 함께 보면, stereographic projection은 sphere 위의 원과 그 사이의 각을 평면의 원(또는 직선)과 그 사이의 각으로 옮긴다.

Exercise 7.4.7 ★★ (Cauchy–Riemann equations) \(\Omega \subseteq \R^2\)가 open set이고 \(f, g\colon \Omega \to \R\)가 매끄러우며, 평면 조각 사이의 map \(\varphi(u, v, 0) = (f(u, v), g(u, v), 0)\)의 Jacobian determinant가 양수라 하자. \(\varphi\)가 local conformal map일 필요충분조건은 \(f_u = g_v\), \(f_v = -g_u\)(Cauchy–Riemann equations)임을 보여라. \((u, v) \mapsto (u^2 - v^2, 2uv)\)는 어디에서 locally conformal인가? [dC §4-2 Exercise 15, modified]

Solution

\(\mathbf{y} = \varphi \circ \iota = (f, g, 0)\)의 coefficient는 \(\bar E = f_u^2 + g_u^2\), \(\bar F = f_uf_v + g_ug_v\), \(\bar G = f_v^2 + g_v^2\)이고 \(\iota\)의 coefficient는 \((1, 0, 1)\)이다. Theorem 7.4.6에서 locally conformal일 필요충분조건은 \(\bar E = \bar G \gt 0\), \(\bar F = 0\)이다. 두 열 \(a = (f_u, g_u)\), \(b = (f_v, g_v)\)로 말하면 “\(a \perp b\)이고 \(\abs a = \abs b \neq 0\)”이다. \(a \neq 0\)에 수직이고 길이가 같은 벡터는 \(a\)를 \(\pm 90^\circ\) 돌린 \(\pm(-g_u, f_u)\)뿐이다. determinant \(f_ug_v - f_vg_u\)가 양수이려면 \(b = (-g_u, f_u)\)여야 하고(\(-\)부호이면 determinant가 \(-(f_u^2 + g_u^2) \lt 0\)), 이것이 \(f_v = -g_u\), \(g_v = f_u\)이다. 거꾸로 Cauchy–Riemann equations와 determinant 양수(곧 \(a \neq 0\))이면 위 조건이 성립한다. \(f = u^2 - v^2\), \(g = 2uv\)이면 \(f_u = 2u = g_v\), \(f_v = -2v = -g_u\)이고 determinant는 \(4(u^2 + v^2)\)이므로, 원점을 뺀 곳에서 locally conformal이다. 원점에서는 미분이 \(0\)이고, 실제로 원점에서 만나는 두 반직선 사이의 각이 두 배가 된다.
