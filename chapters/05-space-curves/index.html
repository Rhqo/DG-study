Sections

  1. 5.1 Curvature of Space Curves Reviewed

    Topics: \(\kappa = \abs{\gamma''(s)}\)와 일반 매개변수의 \(\abs{d\mathbf{t}/dt}/\abs{\gamma'}\), plane curve에서 \(\kappa = \abs{\kappa_s}\), principal normal vector와 curvature vector, osculating plane, space curve의 osculating circle, osculating plane과 osculating circle의 3차 근사 · Running examples: 원(\(\kappa = 1/r\)); helix(\(\kappa = a/(a^2 + b^2)\))

  2. 5.2 Torsion Reviewed

    Topics: binormal vector와 Frenet frame, \(\mathbf{b}' = -\tau\mathbf{n}\), conventions(do Carmo와 부호 반대), unit-speed 공식, 방향·반사와 \(\tau\), \(\tau \equiv 0 \iff\) plane curve(\(\kappa \gt 0\) 필요) · Running examples: 원(\(\tau = 0\)); helix(\(\tau = b/(a^2 + b^2)\))

  3. 5.3 The Frenet–Serret Formulas Reviewed

    Topics: Frenet–Serret formulas와 antisymmetric matrix, Darboux vector(frame의 회전), 일반 매개변수의 공식, twisted cubic · Running examples: helix(\(\kappa, \tau\), Frenet frame); sphere 위 원의 Frenet frame(\(\tau = 0\), \(\mathbf{n}\)과 \(\mathbf{N}\)의 관계)

  4. 5.4 The Fundamental Theorem of Curves Reviewed

    Topics: orthogonal matrix와 \(\R^3\)의 rigid motion, rigid motion은 \(\kappa, \tau\) 보존, \(\kappa \gt 0\)과 \(\tau\)가 rigid motion을 제외하고 곡선을 결정함(linear ordinary differential equation), 상수 \(\kappa, \tau\)는 원과 helix, \(\kappa \gt 0\) 가정의 비예

  5. 5.5 The Local Canonical Form Reviewed

    Topics: normal plane과 rectifying plane, Frenet 좌표의 3차 Taylor 전개, 세 평면으로의 projection, torsion의 부호와 osculating plane을 지나는 방향 · Running examples: helix(정확한 Frenet 좌표)

  6. 5.6 The Rotation Index and the Rotation Index Theorem Reviewed

    Topics: closed curve와 rotation index, 연속인 angle function(uniform continuity), Hopf의 rotation index theorem(simple closed curve의 rotation index \(\pm 1\), 가장 낮은 점으로 부호 판정), curvilinear polygon과 exterior angle(\(\sum\int\kappa_s + \sum\varepsilon_i = \pm 2\pi\)), positively oriented(영역이 왼쪽)이면 \(+2\pi\) · Running examples: 원(\(\pm 1\))

  7. 5.7 The Isoperimetric Inequality (optional) Reviewed

    Topics: signed area, Green's theorem과 곡선이 둘러싸는 넓이, Wirtinger's inequality(Fourier series 없이), \(L^2 \ge 4\pi\abs{A}\)와 등호 조건
