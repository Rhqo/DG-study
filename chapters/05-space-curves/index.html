5. 공간곡선과 프레네 틀

Part I. 곡선과 곡면 · 대응 교재: [dC §1-5–1-7], [dC §5-7 정리 2], [Lee-IRM 정리 9.1]

줄기: T1 곡률이란 무엇인가 (곡선의 \(\kappa, \tau\)) · T5 적분과 위상 (회전지수와 접선회전정리: 가우스-보네의 준비)

이 장의 질문

  • 공간곡선의 모양을 결정하는 데 필요한 양은 몇 개인가?
  • 닫힌 평면곡선은 몇 바퀴 도는가?

이어받는 것

  • 1장 · 외적(정의 1.6.15, 정리 1.6.16), 양의 정규직교기저의 외적(명제 1.6.17), 방향(정의 1.6.11), 행렬식의 성질(정리 1.6.8) — 종법선벡터, 비틀림률 공식, 강체운동
  • 2장 · 1변수 테일러 정리(보조정리 2.2.16) — 접촉원과 국소 표준형; 상미분방정식의 존재·유일성(정리 2.7.6)과 선형 방정식의 전역 해(정리 2.7.12) — 곡선론의 기본정리; 모든 계의 도함수가 \(0\)인 함수(예 2.2.20) — \(\kappa \gt 0\) 가정의 비예; 그린 정리(정리 2.6.13) — 등주부등식(선택)
  • 3장 · 하이네-보렐 정리(정리 3.6.7), 최댓값·최솟값 정리(정리 3.6.10), 르베그 수 보조정리(보조정리 3.6.17)와 균등연속성(따름정리 3.6.19), \(\R\)의 연결 부분집합과 중간값 정리(정리 3.7.4, 따름정리 3.7.6), 경로연결이면 연결(명제 3.7.9) — 접선회전정리의 증명
  • 4장 · 단위접벡터(정의 4.4.1)와 호의 길이 매개화(정리 4.3.9, 나선은 예 4.3.10) — 곡률의 정의; 평면에 놓인 곡선의 \(\abs{\gamma''}\)와 곡률중심(명제 4.5.10), 접촉원(정의 4.5.1) — 공간곡선의 곡률중심과 접촉원(일반화); 평면의 강체운동(4.4절)과 평면곡선의 기본정리(정리 4.4.10, 따름정리 4.4.11) — \(\R^3\)의 강체운동(일반화)과 곡선론의 기본정리; 접선각(보조정리 4.4.8), \(\kappa_s = d\theta/ds\)(정리 4.4.9), 닫힌 곡선의 \(\int\kappa_s \in 2\pi\Z\)(연습 4.4.8) — 회전지수; 구면의 대원과 위도원(예 4.5.11, 예 4.5.12) — 구면 위 원의 프레네 틀

절 목록

  1. 5.1 공간곡선의 곡률 검토 완료

    내용: \(\kappa = \abs{\gamma''(s)}\)와 일반 매개변수의 \(\abs{d\mathbf{t}/dt}/\abs{\gamma'}\), 평면곡선에서 \(\kappa = \abs{\kappa_s}\), 주법선벡터와 곡률벡터, 접촉평면, 공간곡선의 접촉원, 접촉평면·접촉원의 3차 근사 · 기준 예제: 원(\(\kappa = 1/r\)); 나선(\(\kappa = a/(a^2 + b^2)\))

  2. 5.2 비틀림률 검토 완료

    내용: 종법선벡터와 프레네 틀, \(\mathbf{b}' = -\tau\mathbf{n}\), 규약 비교(do Carmo와 부호 반대), 단위속력 공식, 방향·반사와 \(\tau\), \(\tau \equiv 0 \iff\) 평면곡선(\(\kappa \gt 0\) 필요) · 기준 예제: 원(\(\tau = 0\)); 나선(\(\tau = b/(a^2 + b^2)\))

  3. 5.3 프레네-세레 공식 검토 완료

    내용: 프레네-세레 공식과 반대칭 행렬, 다르부 벡터(틀의 회전), 일반 매개변수 공식, 꼬인 삼차곡선 · 기준 예제: 나선(\(\kappa, \tau\), 프레네 틀); 구면 위 원의 프레네 틀(\(\tau = 0\), \(\mathbf{n}\)과 \(\mathbf{N}\)의 관계)

  4. 5.4 곡선론의 기본정리 검토 완료

    내용: 직교행렬과 \(\R^3\)의 강체운동, 강체운동은 \(\kappa, \tau\) 보존, \(\kappa \gt 0\)과 \(\tau\)가 강체운동을 제외하고 곡선을 결정함(선형 상미분방정식), 상수 \(\kappa, \tau\)는 원과 나선, \(\kappa \gt 0\) 가정의 비예

  5. 5.5 국소 표준형 검토 완료

    내용: 법평면과 전직평면, 프레네 좌표의 3차 테일러 전개, 세 평면으로의 사영, 비틀림률의 부호와 접촉평면을 지나는 방향 · 기준 예제: 나선(정확한 프레네 좌표)

  6. 5.6 회전지수와 접선회전정리 검토 완료

    내용: 닫힌 곡선과 회전지수, 연속인 각 함수(균등연속성), 호프의 접선회전정리(단순 닫힌 곡선의 회전지수 \(\pm 1\), 가장 낮은 점으로 부호 판정), 곡선다각형과 외각(\(\sum\int\kappa_s + \sum\varepsilon_i = \pm 2\pi\)), 양의 방향(영역이 왼쪽)이면 \(+2\pi\) · 기준 예제: 원(\(\pm 1\))

  7. 5.7 등주부등식 (선택) 검토 완료

    내용: 부호 있는 넓이, 그린 정리와 둘러싼 넓이, 비르팅거 부등식(푸리에 급수 없이), \(L^2 \ge 4\pi\abs{A}\)와 등호 조건

넘겨주는 것

  • 곡률벡터 \(\gamma'' = \kappa\mathbf{n}\)(5.1절)과, 구면 위 모든 곡선에서 그 \(\mathbf{N}\) 성분이 \(-1/r\)이라는 사실(예 5.3.7(c)) → 8장(법곡률과 뫼니에 정리), 9장(법성분과 접성분(측지곡률)으로의 분해)
  • 구면 위 원의 프레네 틀(예 5.3.7: 위도원은 \(\mathbf{N} = -\sin\theta_0\,\mathbf{n} + \cos\theta_0\,\mathbf{b}\), 대원은 \(\mathbf{n} = -\mathbf{N}\)) → 8장, 9장(측지선 = 대원)
  • 나선의 곡률과 비틀림률(예 5.1.7, 예 5.2.6, 예 5.3.5)과 프레네 틀(예 5.3.3: \(\mathbf{n} = -(\cos, \sin, 0)\)은 수평으로 축을 향함) → 9장(원기둥 위의 측지선: 나선의 주법선이 원기둥의 법선과 평행)
  • 프레네-세레 공식(정리 5.3.1)과 “움직이는 정규직교틀의 변화율은 반대칭” → 9장(곡면에 맞춘 틀), 22장(접속)
  • \(\R^3\)의 강체운동(정의 5.4.3, 명제 5.4.7)과 곡선론의 기본정리(정리 5.4.8) → 9장(보네 정리: 곡면의 기본정리), 22장(평행이동도 구간 전체에서 풀리는 선형 방정식)
  • 접선회전정리(정리 5.6.7)와 곡선다각형의 판(정의 5.6.9, 정리 5.6.11: \(\sum\int\kappa_s + \sum\varepsilon_i = \pm 2\pi\), 가장 낮은 점에서의 부호 판정), 그리고 양의 방향이면 부호가 \(+\)라는 것(명제 5.6.12: 정리 2.6.13의 뜻으로 영역을 왼쪽에 두고 돌면 \(\operatorname{rot} = +1\). 거기서 받아들인 조르당 곡선 정리만 쓴다) → 10장(국소 가우스-보네의 증명. 두 방향 가운데 하나가 양의 방향이라는 것은 이 장에서 증명하지 않았고, 단순 닫힌 곡선에 대해서는 5.7절이 받아들인다)
  • 회전지수와 연속인 각 함수(정의 5.6.3, 보조정리 5.6.6) → 19장(\(\R^2 \setminus \{0\}\) 위의 \(d\theta\)와 차수)
