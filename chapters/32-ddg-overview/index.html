32. Overview: Discrete Curvature of Plane Curves

Track 2. Discrete Differential Geometry · Lectures: [CMU-DDG L1] (video, slides) · References: [Cr ch1]

Threads: T1 What is curvature? (Track 2 starts here: one smooth curvature of a plane curve, four discrete curvatures, and what each one preserves)

Questions

  • smooth plane curve에서는 하나로 정해지는 curvature를 polygon 위에서 정의하려 하면 왜 서로 다른 정의가 여럿 나오고, 각 정의는 smooth curvature의 성질 중 무엇을 정확히 보존하는가?
  • discrete curvature로 curvature flow를 돌리면 smooth flow의 성질을 모두 지킬 수 있는가? 모두 지킬 수 없다면 무엇을 기준으로 정의를 고르는가?

Builds on

  • 가정하는 배경: 다변수 미적분(도함수, chain rule, 적분)과 linear algebra(벡터, inner product, 회전 행렬). Track 2는 Track 3에 의존하지 않는다. Chapter 33, 34와는 서로 독립이다.
  • Track 1: Section 0.2(curvature, signed curvature, osculating circle을 직관으로 보았다. 이 장은 그 discrete 판이다), Section 0.1(differential geometry의 지도).
  • Track 1: Section 31.2(mesh의 discrete curvature를 “무엇을 보존하는가”로 고르는 문제). 이 장은 같은 질문을 가장 단순한 대상인 plane curve에서 다시 묻는다.
  • smooth curve의 정의는 Track 3 Chapter 4의 것을 링크로 상기만 한다(signed curvature Definition 4.4.2). 엄밀한 증명은 Go deeper로 보낸다.

  1. 32.1 What Is Discrete Differential Geometry? Planned

    Topics: DDG의 응용 개관(geometry processing, shape analysis, simulation, architecture; 한 문단씩, 과장 없이); differential geometry와 DDG의 차이: smooth 이론을 근사하는 것이 아니라 discrete 대상 위에서 smooth 이론의 구조(정리)를 정확히 재현하는 정의를 찾는다; “the game”: 동치인 smooth 특징 여럿 → 각각 discretize → 무엇이 보존되는지 비교; 좋은 discrete 정의의 기준(정리 보존, 수렴, 계산 비용); Track 2의 지도(Chapter 32–45의 흐름과 의존 관계, Track 1의 Chapter 31과 Track 3의 관계, 읽는 순서) · Proposition(teaser, 완전한 증명): 반지름 \(r\)인 circle에 내접한 regular \(n\)-gon의 둘레 \(2nr\sin(\pi/n)\)은 \(2\pi r\)로 \(O(n^{-2})\) 수렴하지만, exterior angle의 합은 모든 \(n\)에서 정확히 \(2\pi\)다. “수렴하는 양”과 “정확히 보존되는 양”을 구분하는 첫 예다 · Definitions: 새 dfn 없음(뒤 절이 정의한다) · Running examples: circle에 내접한 regular \(n\)-gon · Smooth vs. Discrete: length(수렴) vs. total turning(정확) · Go deeper: Section 0.1, Theorem 4.2.11(inscribed polygonal path의 극한으로서의 길이), Section 31.2 · Lecture: L1 slides 3–16, 55 · Notes: Cr ch1

  2. 32.2 Curvature of a Plane Curve Planned

    Topics: arc length로 매개화한 plane curve \(\gamma(s)\), unit tangent \(\mathbf{t}\), normal \(\mathbf{n}_s = J\mathbf{t}\), signed curvature \(\kappa_s = \inner{\mathbf{n}_s}{\mathbf{t}'} = \inner{\mathbf{n}_s}{\gamma''}\)(모두 strong, 정의는 링크: Definition 4.4.1, Definition 4.4.2); “curvature는 second derivative이고 부호가 있다”; 동치인 네 smooth 특징(각각 Proposition과 짧은 증명): (A) tangent angle의 변화율 \(\kappa_s = d\theta/ds\)(Theorem 4.4.9 상기), (B) length variation: \(\delta L = -\int\kappa_s\inner{\mathbf{n}_s}{\delta\gamma}\,ds\), 즉 length의 gradient는 \(-\kappa_s\mathbf{n}_s\), (C) Steiner formula: 반시계 방향 simple closed curve의 offset \(\gamma + \varepsilon\mathbf{n}_s\)의 길이 \(L(\varepsilon) = L - \varepsilon\int\kappa_s\,ds\)(작은 \(\varepsilon\)), (D) osculating circle의 반지름 \(1/\abs{\kappa_s}\)(Definition 4.5.1, 세 점을 지나는 원의 극한 Proposition 4.5.7); discrete curve(dfn: vertex \(\gamma_i\)와 그 사이 edge로 된 polygon, closed와 open), edge마다의 discrete tangent와 discrete normal(dfn: edge의 unit vector \(\mathbf{t}_{i,i+1}\)와 \(J\mathbf{t}_{i,i+1}\)); 문제 제기: polygon의 second derivative는 vertex에 몰린 delta라서 pointwise curvature가 없다. 그래서 vertex의 “integrated” 양을 쓴다 · Running examples: circle(\(\kappa_s = 1/r\)), ellipse \((2\cos t, \sin t)\)의 \(\kappa_s(t)\)(verify), flower curve \(r(t) = 1 + 0.3\cos 5t\)의 \(\kappa_s\) 부호 변화 · Conventions: §6.2대로 \(\kappa_s, \mathbf{t}, \mathbf{n}_s = J\mathbf{t}\)(반시계 90°)를 쓴다. Crane(L1)은 \(\kappa, T, N\)을 쓰고 plane curve에서는 부호가 같다. (B), (C)의 부호는 \(\mathbf{n}_s\)와 offset 방향에 따라 바뀌므로 식마다 명시한다 · Helpers: dgdec.curve_tangents, curve_edge_lengths, curve_edge_vectors · Go deeper: Section 4.4, Section 4.5, Section 0.2 · Lecture: L1 slides 17–30 · Notes: Cr §3.3(space curve 관점, Chapter 37에서 다시 쓴다)

  3. 32.3 Four Discrete Curvatures Planned

    Topics: turning angle \(\theta_i\)(dfn: vertex \(i\)에서 들어오는 edge tangent에서 나가는 edge tangent로의 signed angle, \((-\pi, \pi)\)); 네 discrete curvature(dfn, Section 32.2의 (A)–(D)를 하나씩 discretize, 모두 vertex의 integrated 값): \(\kappa^A_i = \theta_i\)(turning angle), \(\kappa^B_i = 2\sin(\theta_i/2)\)(length variation: discrete length의 gradient가 \(\nabla_{\gamma_i}L = -\kappa^B_i\mathbf{n}_i\), \(\mathbf{n}_i\)는 angle bisector normal; Proposition, 완전한 증명), \(\kappa^C_i = 2\tan(\theta_i/2)\)(Steiner: offset edge를 연장해 만나게 하면 길이 변화가 \(\varepsilon\sum\kappa^C_i\)), \(\kappa^D_i = 2\sin\theta_i/w_i\)(세 연속 vertex를 지나는 원의 반지름의 역수, \(w_i = \abs{\gamma_{i+1} - \gamma_{i-1}}\); pointwise); Proposition(증명): offset의 이음새를 원호로 하면 \(\kappa^A\), 현(chord)으로 하면 \(\kappa^B\), edge 연장으로 하면 \(\kappa^C\)가 나온다(“Steiner formula 하나에서 세 정의”); integrated vs. pointwise(dual length \(\bar\ell_i\)로 나누기); Proposition(증명): \(\kappa^B_i, \kappa^C_i = \theta_i + O(\theta_i^3)\)이므로 refinement에서 네 정의 모두 smooth \(\kappa_s\)로 수렴(regular \(n\)-gon과 ellipse로 수치 확인); 무엇을 정확히 보존하는가의 표(total curvature \(= 2\pi\)·turning number는 \(\kappa^A\)만 정확, circle에서 정확한 것은 \(\kappa^D\) 등); “pick the right tool for the job” · Running examples: regular \(n\)-gon(\(\theta_i = 2\pi/n\)이므로 네 값이 모두 닫힌 식), ellipse \((2\cos t, \sin t)\)의 균등 sampling(수렴 그림), flower curve · Smooth vs. Discrete: 하나의 \(\kappa_s\) ↔ 네 개의 discrete curvature · Helpers: dgdec.turning_angles, curvature_turning_angle, curvature_length_variation, curvature_steiner, curvature_osculating_circle, DISCRETE_CURVATURES, curve_vertex_normals, length_gradient, curve_dual_lengths · Overlap: turning angle과 네 curvature의 정의는 여기 한 곳이다. Section 37.4는 이것을 DEC 언어(dual 0-form)로 다시 해석만 한다 · Go deeper: Proposition 31.2.6(surface의 Steiner formula), Section 40.4(polyhedron의 Steiner formula) · Lecture: L1 slides 31–50 · Notes: 노트에는 없다(슬라이드만)

  4. 32.4 No Free Lunch: Discrete Curvature Flow Planned

    Topics: curve shortening flow(dfn: \(\partial_t\gamma = \kappa_s\mathbf{n}_s\); Section 32.2 (B)에 의해 길이를 가장 빨리 줄이는 방향); smooth flow의 세 성질: TOTAL(total curvature \(= 2\pi\)·turning number가 보존된다), DRIFT(중심이 움직이지 않는다. 무엇의 중심인지(vertex 평균인지 arc length centroid인지)와 smooth flow에서 정확히 성립하는지를 verify로 확인하고 정확히 진술한다), ROUND(circle은 모양을 유지하며 \(r(t)^2 = r_0^2 - 2t\)로 줄어든다, 증명); discrete flow: forward Euler \(\gamma_i \leftarrow \gamma_i + h\,\kappa_i\mathbf{n}_i\); 네 discrete curvature(Section 32.3) 각각으로 돌린 flow가 TOTAL, DRIFT, ROUND 중 무엇을 지키는가(Proposition: total curvature를 각 정의 자신의 합 \(\sum_i\kappa^X_i\)로 잴 때 \(\sum_i\kappa^A_i\)는 edge가 뒤집히지 않는 한 언제나 \(2\pi\)·turning number다, length gradient(\(\kappa^B\))는 \(\sum_i\nabla_{\gamma_i}L = 0\)(translation invariance)이라 vertex 평균이 움직이지 않는다, \(\kappa^D\)는 circle 위에 놓인 vertex를 circle 위에 남긴다 등; 증명 또는 반례와 수치. ROUND의 판정에는 circle 위에 고르지 않은 간격으로 놓은 vertex를 쓴다. regular \(n\)-gon은 대칭 때문에 네 flow 모두에서 regular로 남아 판별력이 없다); Crane의 “어떤 discrete curvature도 셋을 동시에 지키지 못한다”는 강의 슬라이드의 주장이므로, 이 절은 네 정의에 대해 확인한 범위만 진술하고 일반적인 불가능성 정리는 쓰지 않는다; 다른 no-free-lunch 예(discrete Laplacian [Wardetzky07], 시간 적분의 보존량)는 한 문단 · Running examples: flower curve \(r(t) = 1 + 0.3\cos 5t\)(flow 예제), circle 위의 고르지 않은 sampling(ROUND), regular \(n\)-gon, ellipse · Algorithm: explicit curvature flow(Implementation, 20줄 안팎) · Conventions: time step은 \(h\)로 쓴다(torsion \(\tau\)와 구분) · Overlap: curve의 gradient flow 일반론, implicit time step, elastic flow는 Section 37.6; surface의 curvature flow는 Section 41.5(explicit)와 Section 42.6(implicit) · Helpers: dgdec.DISCRETE_CURVATURES, curve_vertex_normals, length_gradient · Go deeper: Animation 0.4.4(mean curvature flow), Section 31.3 · Lecture: L1 slides 51–54 · Notes: 노트에는 없다(슬라이드만)
