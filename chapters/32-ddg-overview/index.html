32. Overview: Discrete Curvature of Plane Curves

Track 2. Discrete Differential Geometry · Lectures: [CMU-DDG L1] (video, slides) · References: [Cr ch1]

Threads: T1 What is curvature? (Track 2 starts here: one smooth curvature of a plane curve, four discrete curvatures, and what each one preserves)

Questions

  • smooth plane curve에서는 하나로 정해지는 curvature를 polygon 위에서 정의하려 하면 왜 서로 다른 정의가 여럿 나오고, 각 정의는 smooth curvature의 성질 중 무엇을 정확히 보존하는가?
  • discrete curvature로 curvature flow를 돌리면 smooth flow의 성질을 모두 지킬 수 있는가? 모두 지킬 수 없다면 무엇을 기준으로 정의를 고르는가?

Builds on

  • 가정하는 배경: 다변수 미적분(도함수, chain rule, 적분)과 linear algebra(벡터, inner product, 회전 행렬). Track 2는 Track 3에 의존하지 않는다. Chapter 33, 34와는 서로 독립이다.
  • Track 1: Section 0.2(curvature, signed curvature, osculating circle을 직관으로 보았다. 이 장은 그 discrete 판이다), Section 0.1(differential geometry의 지도).
  • Track 1: Section 31.2(mesh의 discrete curvature를 “무엇을 보존하는가”로 고르는 문제). 이 장은 같은 질문을 가장 단순한 대상인 plane curve에서 다시 묻는다.
  • smooth curve의 정의는 Track 3 Chapter 4의 것을 링크로 상기만 한다(signed curvature Definition 4.4.2, tangent angle Theorem 4.4.9, osculating circle Proposition 4.5.7). rotation index, exterior angle, signed angle은 Section 5.6의 것을 인용한다. 엄밀한 증명은 Go deeper로 보낸다.

Sections

  1. 32.1 What Is Discrete Differential Geometry? Reviewed

    Topics: 수치 근사와 DDG의 차이(discrete 대상 위에서 smooth 구조를 정확히 재현); Proposition 32.1.1(완전한 증명): 원에 내접한 정 \(n\)각형의 둘레 \(2nr\sin(\pi/n)\)은 \(0 \lt 2\pi r - L_n \le \pi^3r/(3n^2)\)로 수렴하고 exterior angle의 합은 모든 \(n\)에서 정확히 \(2\pi\); “the game”의 세 단계와 좋은 정의의 기준(구조 보존, 수렴, 비용), no free lunch 예고; 응용 개관(강의 슬라이드의 분야 목록을 따라, 이 study set의 해당 장과 함께); Track 2의 지도(장 의존 관계 그림, 장마다의 질문과 강의 번호, Chapter 31·Track 3과의 관계) · Definitions: 새 dfn 없음 · Running examples: 원에 내접한 정 \(n\)각형 · Smooth vs. Discrete: length(수렴) vs. total turning(정확) · Exercises: 5개(Coding 1) · Lecture: L1 slides 3–16, 55 · Notes: Cr ch1

  2. 32.2 Curvature of a Plane Curve Reviewed

    Topics: signed curvature 상기(\(\mathbf{t}' = \kappa_s\mathbf{n}_s\), \(\mathbf{n}_s = J\mathbf{t}\); 이계도함수이고 부호가 있다); 동치인 네 smooth 특징(Proposition 32.2.2–32.2.5): (A) \(\int_a^b\kappa_s\,ds = \varphi(b) - \varphi(a)\), (B) first variation \(\delta L = -\int\kappa_s\inner{\mathbf{n}_s}{\eta}\,ds\)(증명), (C) Steiner formula \(L(\gamma + \varepsilon\mathbf{n}_s) = L - \varepsilon\int\kappa_s\,ds\)가 \(\abs{\varepsilon}\max\abs{\kappa_s} \lt 1\)에서 정확(증명), (D) 세 점을 지나는 원의 극한(Proposition 4.5.7 상기); discrete curve(dfn), discrete tangent \(\mathbf{t}_i = e_i/\ell_i\)와 discrete normal \(J\mathbf{t}_i\)(dfn, edge \(i\)는 \(\gamma_i \to \gamma_{i+1}\)); polygon에는 pointwise curvature가 없고 tangent angle이 계단 함수 · Running examples: 원, 타원 \((2\cos t, \sin t)\)(\(\int\kappa_s^2\,ds = 6.636\), offset 길이), flower curve(polar coordinates로 쓴 (32.2.2), \(\kappa_s\)의 부호가 10번 바뀜) · Conventions: \(\kappa_s, \mathbf{t}, \mathbf{n}_s\) vs Crane의 \(\kappa, T, N\)(부호 같음), tangent angle은 \(\varphi\) · Implementation: discrete tangent와 normal · Exercises: 5개(Coding 1) · Lecture: L1 slides 17–30 · Notes: Cr §3.3

  3. 32.3 Four Discrete Curvatures Reviewed

    Topics: turning angle \(\theta_i = \angle(\mathbf{t}_{i-1}, \mathbf{t}_i)\)(dfn); Proposition 32.3.4(증명): 닫힌 discrete curve에서 \(\sum\theta_i = 2\pi k\); dual length \(\bar\ell_i\)와 integrated/pointwise; 네 discrete curvature(dfn: turning-angle, length-variation, Steiner, osculating-circle curvature); Proposition 32.3.6(증명): \(\nabla_{\gamma_i}L = \mathbf{t}_{i-1} - \mathbf{t}_i = -\kappa^B_i\mathbf{n}_i\), vertex normal \(\mathbf{n}_i = J\bar{\mathbf{t}}_i\); Proposition 32.3.7(증명): offset의 이음새를 원호/현/edge 연장으로 하면 \(\kappa^A/\kappa^B/\kappa^C\)(C는 양쪽 방향, convex하지 않아도 정확); Proposition 32.3.8(증명): circumcircle 반지름 \(1/r_i = \abs{\kappa^D_i}\), \(\inner{c_i - \gamma_i}{\mathbf{n}_i} = \bar\ell_i/\kappa^B_i\); Proposition 32.3.9–32.3.10: 작은 각에서 \(O(\theta^3)\) 차이, \(O(h^2)\) 수렴(Proof sketch와 수치); 무엇을 보존하는가의 표 · Running examples: 정 \(n\)각형(B, D는 정확히 \(1/r\)), 타원 sampling의 수렴 그림, 고르지 않은 원(D만 정확), flower curve · Implementation: 네 curvature · Exercises: 6개(Coding 1) · Lecture: L1 slides 31–50 · Notes: 노트에는 없다(슬라이드만)

  4. 32.4 No Free Lunch: Discrete Curvature Flow Reviewed

    Topics: curve shortening flow(dfn)와 \(dL/dt = -\int\kappa_s^2\,ds\); smooth flow의 TOTAL, DRIFT(정확히는 \(\int\partial_t\gamma\,ds = 0\). 대칭이 없는 limaçon \(r = 1 + 0.4\cos t\)에서는 arc length centroid가 움직인다), ROUND(\(r^2 = r_0^2 - 2t\)), 받아들이는 사실(존재·유일성, Gage–Hamilton, Grayson); discrete curve shortening flow(dfn: forward Euler \(\gamma_i \leftarrow \gamma_i + h\boldsymbol{\kappa}^X_i\), A·B·C는 \(\kappa^X_i\mathbf{n}_i\), D는 circumcenter 방향 \((c_i - \gamma_i)/r_i^2\)); 정다각형은 네 flow 모두에서 정다각형(판별력 없음); 증명: A는 TOTAL, B는 vertex 평균 고정, D는 원 위의 vertex를 동심원 위에 남김; 수치 반례(대칭 없는 flower 다각형, 고르지 않은 원); 일반적인 불가능성은 강의 슬라이드의 주장으로만 소개; 다른 no free lunch(discrete Laplacian, 시간 적분) · Running examples: flower curve(smooth flow 그림, 대칭 없는 sampling), 고르지 않은 원(ROUND), 정 \(n\)각형, 타원 · Implementation: explicit curvature flow · Exercises: 6개(Coding 2) · Lecture: L1 slides 51–54 · Notes: 노트에는 없다(슬라이드만)
